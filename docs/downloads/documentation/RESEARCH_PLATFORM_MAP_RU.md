### Файлы каждого нацпроекта

Все пути ниже указаны относительно `public/data/projects/<project_id>/`.

- `foundation.json`: аудит реестра, доступность региональной панели, сводка документальных узлов, карта двенадцати будущих разделов, источники с квалификацией и ссылками, небольшие CSV для скачивания.
- `indicators.json`: исходный аудит каждого показателя и последние доступные наблюдения по России. Для каждого наблюдения сохранены идентификаторы источника, ряда, снимка и исходной ячейки, значение, единица, категория, период, периодичность и дата получения.
- `methods.json`: 39 строк матрицы методов. Статусы и ограничения перенесены из исследовательского выпуска; статус выполненного вычисления сам по себе не означает готовность авторской страницы.

Общие файлы:

- `publication.json`: инвентаризация опубликованных данных по нацпроектам.
- `provenance.json`: SHA-256 исходных таблиц и базы данных, даты срезов, правило отбора статистики.
- `export-validation.json`: проверяемые итоги выгрузки.
- `publications.json`: отдельный реестр проверенных авторских страниц; он управляется сборщиком контента, а не импортёром данных.

В `public/downloads/projects/shared/` лежат точные копии четырёх компактных таблиц выпуска: аудит показателей, аудит нацпроектов, матрица методов, применимость методов. Полная база SQLite, рабочие копии корпуса и временные результаты в сайт не включены.

## Правило актуальности

Для национального наблюдения одновременно проверяются следующие условия:

1. Снимок совпадает с `current_sources` по источнику.
2. Происхождение снимка: `live_emiss`.
3. Нормализованное наблюдение имеет статус `usable`, без нарушения допустимой области и без выхода за дату среза.
4. Значение не отсутствует, конец периода не позднее 15 октября 2026 года.
5. Внутри каждого ряда выбирается последнее допустимое наблюдение. Ряды с различными категориями, единицами или периодичностями сохраняются раздельно.

Все 346 опубликованных наблюдений дополнительно сопоставлены с исходными ячейками таблицы `observations`: значение и единица измерения совпадают, происхождение `live_emiss` и принадлежность текущему снимку подтверждены. Исторические снимки не служат запасной подстановкой при отсутствии актуальных данных.

Экспортёр основы сохраняет последний подтверждённый снимок исследовательского выпуска. В `2.1.0-youth.1` для «Молодёжи и детей» добавлен отдельный текущий слой, воспроизводимый сборщик `refresh_youth_emiss.py` и подключение к общему workflow; он не требует переимпорта всей базы. Девять остальных проектов пока используют исследовательский экспорт. Дата проверки источника и дата пригодных числовых данных разделены.

## Ограничения интерпретации

Документальная связь результата с задачей не доказывает причинное влияние на показатель. Совместная принадлежность задаче и лексическое сходство выделены в исследовательском выпуске как разные типы доказательств. Причинный эффект нацпроектов в существующих источниках не идентифицирован.

Региональная многомерная панель может использовать ограниченный набор признаков и отдельную периодичность. Статус `computed` означает выполненное вычисление на допустимых входах, а не полную сопоставимость всех показателей проекта. При отсутствии устойчивого разбиения на кластеры соответствующее ограничение сохраняется.

Часть документов представлена вторичными HTML-страницами паспортов. Их версия и дата обновления сайта не тождественны дате утверждения оригинала. Поле `qualification` и исходная ссылка сохраняются для каждого такого источника. Источники не получают придуманных дат утверждения.

Финансовые величины из исследовательской сводки сохраняются в тысячах рублей, когда это указано в имени поля. Они не смешиваются с рублями или бюджетными расходами другой редакции. Авторская интерпретация должна отдельно проверять единицы, состав и сопоставимость паспортов.
