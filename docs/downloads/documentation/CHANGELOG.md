# 1.2.1

Публикация в `Arseniy24RUS/family` с обязательной проверкой Playwright через HTTP перед каждым deployment и плановым обновлением. Исправлены UTF-8 на Windows, блокировка XLSX и зависимость браузерных тестов от виртуальной подмены файлов.

Загрузчик ЕМИСС использует действующую форму `/indicator/downloadData?format=sdmx`, сессионный одноразовый токен и повторный запрос свежей формы после временной ошибки. Периоды и единицы читаются из атрибутов SDMX; распознаются сокращения территориальных классификаторов и пропуск «–». Все 16 ID проверены по каталогу; для бедности сохраняется годовая периодичность. Пустые ещё не опубликованные месяцы не блокируют прогнозные ряды.

Возрастные базы загружаются из настоящих XLSX. Неполная старая история не блокирует актуальные входы. Режим `cohort-monthly/1.2.1` распределяет отрицательное сальдо по существующим подкогортам с сохранением общего потока; прежние JSON без нового режима воспроизводятся алгоритмом 1.1.1. Невалидный импорт не стирает предыдущий пользовательский вход.

# 1.2.0

Полная переработка оболочки по палитре GeoTalent: белая шапка с тремя логотипами без подписей, светлая боковая навигация, сине-бирюзовые визуализации, компактная иерархия элементов. На мобильных экранах логотипы расположены во второй строке шапки.

Новая модель `monthly-nonlinear-ensemble/1.2.0` объединяет пять алгоритмов. Гармоника и квазипериодический GP оцениваются по данным, а не задаются рисунком линии. GP использует GLS-оценку среднего тренда. Добавлены разложение кривой, просмотр ближайших 24 месяцев, предиктивные проверки всего ансамбля без будущих ошибок в весах и явное сравнение с сохранением последнего уровня. Пересчитаны 172 ряда, расширены CSV/JSON, автономный Python-пакет и Colab. Требование для вычисления прогнозов — NumPy 2.3.5; браузеру NumPy не нужен.

Сохранена совместимость воспроизведения JSON прежней модели 1.1.1. Исходные статистические значения, оригинальные скрипты, текст экспертизы и её сохранённые прогнозы не изменены. Расписание Actions и ограничения внешней загрузки остаются прежними.

# 1.1.0

Новая палитра YlGnBu, точное название платформы, институциональные ссылки и страница авторов. Отдельные обновляемые прогнозы СКР и СКР3+; помесячная когортно-компонентная модель с открытой группой 100+.

Исходные результаты экспертизы не переписаны. Новый прогноз показателей обозначен версией monthly-log-ensemble/1.1.1. Передвижка обозначена cohort-monthly/1.1.1. Внешние возрастные базы запрашиваются при публикации; отсутствующие базы не подменяются синтетическими.
