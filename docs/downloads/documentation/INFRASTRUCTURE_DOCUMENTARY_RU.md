## Цели и карта соответствия

Полное извлечение сохраняет 51 исходную карточку показателей и 969 ячеек по годам 2018–2036. Для 32 карточек текущего каталога выделены цели на 2025–2030 годы: 192 ячейки, 188 чисел и четыре пропуска. Число 32 описывает карточки интерфейса, а 51 – все исходные карточки национального и федеральных уровней; повторение показателя на разных уровнях не создаёт новый показатель каталога.

При выборе основной траектории приоритет имеет национальная карточка, если она присутствует, иначе используется соответствующая федеральная. Другие исходные карточки и расхождения значений сохраняются. Редакции не склеиваются, национальная и федеральная цель не суммируются. Каждая ячейка имеет документ, показатель, год, исходный текст и точный DOM-указатель.

Карточка федерального проекта И8 о доле автомобильных дорог Минобороны, соответствующих нормативным требованиям, сохранена полностью, но не имеет подтверждённого соответствия унаследованному реестру и источнику ЕМИСС. Поля кода каталога и ID источника остаются пустыми; новый статистический ID не придуман. Полный набор карточек доступен в `targets.allCards` полного документального экспорта.

Карта сопоставления связывает цель общего ввода жилья именно с 59263. Ряды многоквартирного жилья 59262 и жилья, построенного населением, 59993 не получают автоматически эту цель. Преобразование масштаба единицы применяется только по явно установленному правилу. Методический разрыв 62872 и накопленная месячная численность 62882 не обходятся подбором удобного периода.

## Тексты и независимый пересчёт

Текстовый корпус включает 98 паспортов двенадцати национальных проектов. Для «Инфраструктуры для жизни» используются 13 документов. Извлекаются содержательные фрагменты паспортов, выполняются нормализация регистра, замена «ё» на «е» и удаление точных повторов внутри документа. Биграммы не переходят через границы исходных фрагментов. Финансовые таблицы и служебная разметка не должны искусственно доминировать в тематическом профиле.

Базовый TF-IDF использует униграммы и биграммы, логарифмическое преобразование частот, сглаженный IDF и нормировку L2. Закреплённый список из 120 стоп-слов происходит из включённого исследовательского кода; его совпадение с нераскрытым авторским списком не установлено. Восемь тематических словарей являются явной самостоятельной реализацией. Поэтому все результаты повторного расчёта имеют соответствующее происхождение и не заменяют авторские таблицы.

Корпус содержит 104 тематические ячейки – восемь тем для 13 документов – и 605 дословных контекстов. Каждый контекст связан с документом и исходным фрагментом. Полные тексты и контексты распределены по 13 файлам `documentary-text/<document_id>.json` и подгружаются при выборе документа. Лёгкий обзор сохраняет ссылки и агрегаты.

Расчёт чувствительности содержит шесть спецификаций: базовую, со стеммингом, только униграммы, равные веса национального и федерального уровней, только федеральные и только национальные паспорта. Для равных уровней сначала вычисляются средние нормированных векторов документов внутри каждого уровня, затем берётся их смесь 0,5/0,5 и выполняется итоговая нормировка. Дополнительной нормировки среднего внутри каждого уровня нет.

Во всех шести вариантах ближайшим проектом остаётся «Эффективная транспортная система». Базовый косинус в пересчёте равен примерно 0,1551, тогда как в авторском отчёте приведено 0,154. Корреляция рангов с базовым вариантом составляет около 0,9091 для стемминга, 0,9909 для униграмм, 0,6909 для равных уровней, 0,9818 для федеральных документов и 0,0455 для национальных. Совпадение ближайшего соседа не устраняет различия чисел и не означает установленную организационную или финансовую связь.

Точный авторский код не предоставлен; `authorExactCodeAvailable` имеет значение `false`. Расхождения в токенизации, словаре и пространстве признаков сохраняются в `replicationAudit`. Платформа не подгоняет независимые расчёты под авторские итоги и не объявляет небольшое расхождение технически устранённым без доказательства.

В `documentary_full.json` сохранены все исходные финансовые строки, результатные годы, детальные бюджетные строки и все карточки целей. Эти тяжёлые поля намеренно исключены из начального `documentary.json`, поскольку интерфейс не использует их при каждом открытии страницы. Поле `runtime_omissions` перечисляет полные выгрузки, а `full_export_url` ведёт к полному JSON. Такое разделение уменьшает начальную загрузку и не удаляет источники или наблюдения.

Следующие команды выполняются из корня отдельной рабочей копии и записывают производные файлы в неё. Обычное воспроизведение закреплённого выпуска работает без сети:

```bash
python -m pip install -r scripts/requirements-analytics.txt
python -X utf8 scripts/build_infrastructure_expertise.py
python -X utf8 scripts/build_infrastructure_documentary.py
python -X utf8 scripts/build_infrastructure_analytics.py
python -X utf8 -m unittest discover -s tests -p "test_infrastructure_documentary.py" -v
```

`prepare_infrastructure_documentary.py` предназначен для первоначального приёма источников, а не для штатного получения текущих данных. Обновление паспортной редакции требует отдельной проверки исходных байтов, структуры, единиц, охвата, карты показателей и расхождений. Новая авторская редакция требует рендера DOCX, просмотра содержательных страниц и обновления карты страниц, связанной с SHA. Обычная сборка текущего отчёта использует включённую карту и не требует повторного рендера.

Двадцать предметных тестов документального блока прошли успешно. Они сверяют оригинальный DOCX и его содержательные абзацы, все табличные ячейки, изображения, сноски и формулы; непосредственно читают исходные HTML для 969 целевых, 524 паспортных финансовых и 268 бюджетных ячеек; проверяют недопущение повторного суммирования вложенных строк, горизонты, пустые финансовые записи, уникальность карточек и области задач. Отдельно проверены дословность 605 контекстов и открытая маркировка расхождений повторного текстового анализа. Бюджетная строка нумерации колонок исключается регрессионной проверкой.

Сводный результат предметных проверок, включая независимую сверку бюджетной таблицы, включён в [INFRASTRUCTURE_SOURCE_AUDIT.json](INFRASTRUCTURE_SOURCE_AUDIT.json).
