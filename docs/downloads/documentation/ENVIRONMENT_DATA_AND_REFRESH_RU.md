# Экологические данные и обновление ЕМИСС

## Происхождение

Нормализованные ряды находятся в `public/data/projects/environment/series/`. Для каждого источника сохранены описание, SHA-256, происхождение и первичный комплект в `public/downloads/projects/environment/statistics/`. Срез включает 18 карточек и 18 источников. Дата получения исходных файлов – 15 октября 2026 года.

Импорт `scripts/import_environment_release.py --from-inputs` работает с включёнными файлами. Внешняя SQLite-база для обычной сборки не требуется. `scripts/build_environment_analytics.py` пересчитывает описательные результаты из опубликованных серий. Браузер загружает историю выбранного источника по запросу.

## Наблюдения и границы расчёта

Запись сохраняет исходное значение, подпись периода, частоту, территорию, категорию и единицу. Отдельные поля задают аналитический период, нормализованную частоту и правило преобразования. Число, пропуск и исключение различаются. Пропуски не заполняются нулями или значениями соседнего периода.

| Случай | Правило |
|---|---|
| Доли обработки и захоронения ТКО | Допустимы значения 0–100, доли не являются дополнениями друг друга |
| Лесовосстановление | Отношение площадей допускает значения выше 100, знаменатель имеет двухлетний сдвиг |
| Нулевой знаменатель лесного отношения | Методика предусматривает значения 0 или 125%, для интерпретации нужны компоненты |
| Городские индексы воздуха | 12 и 29 территорий, базы 2017 и 2020 годов, отдельный географический уровень |
| Накопление | С начала года и с начала проекта учитываются раздельно, накопленный объём не приписывается последнему месяцу |
| Годовой результат | Используются самостоятельные годовые строки, декабрь автоматически не превращается в год |
| Индекс вторичных ресурсов | Несогласованность исходных метаданных с действующей методикой блокирует временные разности и целевые сопоставления |
| Нулевой план будущего года | У 62861 опубликованы нули 2028–2030 без признака прекращения. Числа сохраняются, автоматическая желательная траектория к нулю блокируется |
| Лесные пожары | Исходный ряд сохраняется, действующие целевые сопоставления и сценарии отключены |

Методика лесного отношения: [приказ Рослесхоза № 238 от 17 апреля 2026 года](https://www.consultant.ru/document/cons_doc_LAW_547263/9fbb91a978d21ed646107611b1a476471472a280/). Официальный перечень: [Росстат, «Сохранение лесов»](https://rosstat.gov.ru/storage/mediabank/FP1506_N.htm). Формула использует выбытие за год `t−2`. Невзвешенное среднее региональных отношений не заменяет национальное отношение сумм.

Для экономики замкнутого цикла используется [перечень Росстата](https://rosstat.gov.ru/storage/mediabank/FP1502_N.htm). [Приказ № 416 от 28 июля 2026 года](https://legalacts.ru/doc/prikaz-minprirody-rossii-ot-28072026-n-416-o-vnesenii/) заменяет ответственного должностного лица в приказах 690, 691 и 761. Само изменение 416 не обозначается разрывом формулы. Переход от методики 692 к 761 требует отдельного согласования с исходными метаданными.

## Территории и сравнения

Региональная карта включает сопоставимые строки выбранного источника, категории и периода. Агрегаты и муниципальные территории не превращаются в субъекты Федерации. Исходное название территории остаётся в записи. Невзвешенные распределения описывают доступные регионы и не подменяют показатель Российской Федерации.

Пара долей ТКО за 2025 год имеет 85 полных наблюдений. Дополнительный расчёт без пары 0/0 Еврейской автономной области сохраняет 84. Кластеризация, PCA, Isolation Forest и индексы Moran для этой экспертизы не заявляются. Прежние счётчики исследовательского этапа хранятся отдельно от текущего результата.

Цели поступают из датированной паспортной републикации. Проверяются источник, единица, география, частота и статус показателя. Разность факта 2025 года с целью из октябрьской редакции 2026 года имеет описательное значение. Выполнение первоначального задания таким сопоставлением не удостоверяется.

Независимый аудитор `scripts/audit_environment_sources.py` читает физические XLS, SDMX и grid JSON без импорта производственных нормализаторов. Команда `python scripts/audit_environment_sources.py --output <файл_JSON>` сверяет состав, исходные измерения, значения и контрольные суммы всех 18 источников.

## Команды

```bash
python scripts/import_environment_release.py --from-inputs
python scripts/build_environment_analytics.py
python scripts/refresh_environment_emiss.py --source 62781
npm run build
npm run validate
```

Обычная сборка не делает сетевых запросов. Прямое обновление ограничивает время запроса, проверяет формат, единицы и периоды, контролирует потери наблюдений и записывает результат. При недоступности источника остаётся предыдущая проверенная публикация. Время проверки и дата получения данных имеют разные поля.

Workflow включает параметр `environment_source`, отдельный статус `environment_state`, перенос проверенных результатов, сводку и браузерные проверки. Расписание платформы не означает известный день публикации ЕМИСС. Существующие настройки доступа и VPN сохранены.
