# Происхождение и воспроизводимость

## Материалы исследования

Основной источник — «Экспертиза нацпроекта Семья 14.05.2026(7).docx», авторы: Ростовская Т.К., Ситковский А.М., Синельников А.Б., Архангельский В.Н. Его браузерное имя для скачивания — `expertise_2026-05-14.docx`. На тематических страницах указаны разделы и страницы источника. Документ не заменён автоматически обновлённой редакцией.

Статистические CSV, метаданные, финансовые таблицы, матрицы, пространственные и текстовые результаты извлечены из предоставленного архива экспертизы. XLS-источники помещены в `emiss_original_xls.zip`, исходная база — в `original_database.zip`. В `documents/` сохранены четыре PDF проектного корпуса. GeoJSON — предоставленный пользователем `ru_regions.geojson`; исходный файл доступен без упрощения геометрии.

Учебные материалы предыдущего этапа — `seminar_methods.docx` и `seminar_colab.zip`. Аналитическая записка сохранена отдельно и не заменяет полный отчёт как основной источник. Сведения, имеющиеся только в записке, не выданы за вычисления полной экспертизы.

## Исходный код и новый код

`code/original/` содержит шесть полученных скриптов: `np_family_analysis_pipeline.py`, `add_advanced_analysis_v2.py`, `build_v2_full.py`, `fix_projected_geo_maps_v3.py`, `fix_figures_and_report_v5.py`, `fix_figures_and_report_v6.py`, а также их файл зависимостей. Они сохранены как материалы исходного проекта, включая рабочие пути и зависимости. Наличие этих файлов не означает, что восстановлен весь первоначальный программный конвейер или запуск каждого скрипта гарантирован на новом компьютере.

`code/platform/` содержит новые программы подготовки браузерных данных, обновления ЕМИСС, проверок и повторения лабораторных расчётов. `code/frontend/` — исходный интерфейс и браузерные формулы. Разделение отражает происхождение, а не качество одного набора по сравнению с другим.

Новая раскладка региональной сети служит только читаемому расположению исходных узлов и рёбер. Новое упрощение геометрии служит быстрому отображению. Они не являются заново оценёнными эмпирическими результатами экспертизы.

## Сохранённые расхождения

| Вопрос | Представление в платформе |
|---|---|
| Два источника младенческой смертности | Отдельные `data_31` и `data_32`, с самостоятельными периодами и исходными строками |
| Год, месяц и накопительный период | Разные ключи; не считаются взаимозаменяемыми |
| Итоговая кластеризация и файл выбора k | Итоговый состав 56/19/10 не заменён распределением 59/7/19 из другой сохранённой процедуры |
| Пространственные веса и перестановки | Исходные Moran/LISA отдельно от новой лаборатории с повторной нормировкой и 999 перестановками |
| Прогноз бедности, упирающийся в ноль, и прогноз доли выше 100 | Исходные значения не исправлены незаметно; интерпретационные предупреждения рядом с прогнозом |
| Часть долей наблюдения детей выше 100 | Сохранены исходные числа и диагностические флаги; нет автоматического обрезания |
| Разные базы бедности в паспорте и ЕМИСС | Различие отражено как вопрос сопоставимости, а не заменено выбранной «правильной» базой |
| Нулевое совпадение словаря темы здоровья | Результат конкретного текстового извлечения и словаря, не доказательство отсутствия медицинских мероприятий |
| Перекрывающиеся источники финансирования | Не представлены как независимые части, автоматически складывающиеся в 100% |

Полная экспертиза содержит собственные оценочные формулировки и условные шкалы. Тематические страницы отделяют наблюдения, описание авторской методики и предметные основания выводов; полные исходные формулировки доступны в документе. Обновление статистики не исправляет и не переписывает их автоматически.

## Контроль файлов

`downloads/index.json` перечисляет опубликованные материалы, их размеры и SHA-256. `npm run validate` пересчитывает хеши готовой сборки. Хеш удостоверяет неизменность конкретного файла внутри выпуска, но не достоверность его содержимого. Для новых ЕМИСС-запросов дополнительно сохраняются хеши XML, фильтры и журнал пересмотров; предшествующие версии доступны в Git.

Для научной публикации следует ссылаться на авторов экспертизы, конкретный статистический источник, период и версию расчёта. Ссылка только на главную страницу платформы не заменяет описание выборки, весов, параметров алгоритма и правил обработки пропусков.
