# Источники и условия использования

Исследовательские материалы предоставлены владельцем проекта для подготовки этой платформы. Авторство основной экспертизы: Ростовская Т.К., Ситковский А.М., Синельников А.Б., Архангельский В.Н. Исходные документы, статистические файлы, картографическая основа и ранее написанные программы сохраняют собственное происхождение и условия использования. Этот комплект не устанавливает для них новую лицензию и не объявляет сторонние материалы общественным достоянием.

Схема адаптера ЕМИСС основана на коде из предоставленного архива `CDO_dashboard_external_audit_2026-06-26`. Адаптированы чтение каталога, извлечение метаданных фильтров, сессионная загрузка SDMX и разбор ответа; добавлены контракты именно для набора «Семья», публикация статических файлов, диагностика и тесты сохранения последней корректной версии.

Новый интерфейс, сборка, схемы данных, лабораторные вычисления и документация подготовлены для данного проекта. Код GeoTalent, его логотипы и шрифтовые файлы в комплект не включены. Визуальное направление использовано как ориентир по запросу владельца.

До внешней публикации владелец репозитория должен подтвердить возможность открытого распространения включённых исследовательских документов и файлов. Персональные реестры получателей поддержки, ключи API, пароли и настройки доступа не требуются для работы сайта и не должны добавляться в публичный репозиторий.

Платформа не является официальным сайтом ЕМИСС, Росстата или Правительства Российской Федерации. Даты, версии, определения и ограничения источников являются частью результата. Не следует цитировать новые лабораторные расчёты как исходные результаты экспертизы без соответствующего обозначения.
