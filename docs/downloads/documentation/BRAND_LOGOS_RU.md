# Логотипы национальных проектов

В версии платформы от 30 октября 2026 года двенадцать логотипов приведены к вариантам страницы 47 брендбука «Национальные проекты России», 2025. Страница 47 совпадает с физической нумерацией PDF. Знаки и надписи извлечены как векторные контуры; перерисовка и подстановка шрифтов не применялись.

## Происхождение

Источник – предоставленный пользователем файл `Brendbuk_Natsproekty_Rossii_2025(1).pdf`, SHA-256 `eb480ed2200e61c56cdec8f98299b6594a7a0766bf6ae88c8bd864a5552e3485`. Полный исходный PDF для работы сайта не требуется.

`BRAND_LOGOS_PROVENANCE.json` содержит координаты каждого знака, номера исходных путей, SHA-256 исходного фрагмента при контрольной растеризации, SHA-256 канонических атрибутов исходных путей и каждого итогового SVG. Идентичный манифест опубликован как `public/assets/brand/manifest.json`.

`BRAND_LOGOS_PREVIOUS_ASSETS.json` сохраняет происхождение использовавшихся ранее самостоятельных SVG. Предыдущий оригинал логотипа технологий здоровья также остаётся в архивных материалах соответствующего проекта.

## Размещение

Каждый файл расположен по стабильному адресу `assets/brand/<project_id>.svg`. Размер SVG – 134,51 × 111,92; область просмотра включает по 2 пункта вокруг границ знака. Изображения прозрачные, не загружают внешние ресурсы и не требуют шрифтов. Все двенадцать SVG занимают 133 655 байт.

Надписи сохранены именно в вариантах страницы 47: в частности, «ЭКОЛОГИЯ», «АКТИВНАЯ ЖИЗНЬ», «ТЕХНОЛОГИИ ЗДОРОВЬЯ», «ЭКОНОМИКА ДАННЫХ». Полные названия проектов используются в заголовках и альтернативном тексте изображений.

Проектные цветовые темы сохранены. У «Семьи» цвет визуализаций `#2947A0` отличается от бирюзового официального знака `#00AECD`, как и было задумано пользователем. В знаке технологий здоровья со страницы 47 цвет `#008BBF`; существующая тема проекта `#0A8BBF` сохранена. Другие одиннадцать основных цветов логотипов совпадают с предыдущими файлами.

## Повторное извлечение

Скрипту требуются Python, PyMuPDF и lxml. Pillow нужен только для необязательного контактного листа. Из корня платформы:

```bash
python scripts/extract_brand_logos.py --source /path/to/Brendbuk_Natsproekty_Rossii_2025.pdf
```

Скрипт проверяет точный SHA-256 исходного брендбука, число путей и размеры страницы. По умолчанию он обновляет `public/assets/brand/` и `documentation/BRAND_LOGOS_PROVENANCE.json`. Параметры `--output-dir` и `--manifest` задают другие адреса. Параметр `--qa-dir` создаёт внешнюю папку с исходными фрагментами, изображениями результата и контактным листом; материалы этой проверки не нужны для публикации сайта.

Проверки `tests/brand-logos.test.mjs` подтверждают целостность всех файлов, цвета, неизменность геометрии по каноническим атрибутам и отсутствие внешних зависимостей. Исходные фрагменты и итоговые изображения дополнительно сопоставлены визуально.
