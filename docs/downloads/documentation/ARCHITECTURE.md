# Архитектура платформы

## Задача и технический выбор

Платформа одновременно служит научному докладу, самостоятельному чтению исследования и исследованию таблиц. Главные задачи визуализации — пространственное сопоставление, временная динамика, структура расходов, многомерное сходство и прослеживание связей мероприятий. Основной аналитический объект остаётся один; тематические страницы разделяют исследовательские вопросы.

Интерфейс построен на стандартных ES-модулях JavaScript, DOM и SVG. Развёртывание не зависит от CDN, npm-пакетов, картографических сервисов, токенов, загружаемых шрифтов или серверного приложения. Сборщик на Node.js использует только стандартную библиотеку. Python работает локально или в GitHub Actions, не на сервере GitHub Pages. Расчёты k-means и Moran I выполняются в выделенном Web Worker.

React/Vite не требуются для запуска данного комплекта. Отсутствие стороннего фронтенд-рендерера компенсируется разделением ответственности: shell, страницы, компоненты, чистые статистические функции, данные и отдельный вычислительный worker.

## Структура

`src/app.js` управляет оболочкой, маршрутом и состоянием. `src/core/data.js` загружает и проверяет слои данных, выбирает совместимые периоды и обрабатывает территориальные варианты. `src/core/stats.js` содержит чистые статистические функции. `src/core/worker.js` выполняет затратные расчёты вне основного потока.

`src/components/charts.js`, `map.js` и `network.js` отвечают за графики, картографию и сети. `src/pages/` — тематические поверхности. `src/content/sections.js` — содержание 12 разделов, объяснения методов, матрица сфер жизни и предложения авторов.

`public/data/baseline/` неизменяем для обычного цикла обновления. `public/data/latest/` — публикуемая история проверок и последние корректные загрузки. `public/downloads/` содержит первичные материалы и машинно читаемые выгрузки.

`scripts/build_data.py` готовит браузерные структуры из включённых исходников; не переобучает исходные прогнозные модели. `scripts/build.mjs` публикует исходный код и документацию для скачивания, собирает worker, создаёт контрольные суммы и копирует готовый сайт в `docs/`.

## Состояние интерфейса

Страница, вкладка, источники, период, выбранные регионы и основные фильтры хранятся в hash-параметрах URL. Кнопка «Ссылка» копирует текущий адрес; обычные переходы браузера восстанавливают представление. Временное положение карты при ручном перетаскивании и промежуточные неэкспортированные расчёты не являются постоянным хранилищем. Параметры лаборатории сохраняются вместе с экспортом результата.

Асинхронное открытие страницы защищено счётчиком последовательности: более старый ответ не заменяет позднее выбранную страницу. Ошибка запроса показывает сообщение и возможность повторения, а не пустую аналитическую панель.

## Визуализации и проверяемые соглашения

| Слой | Реализация и аналитическая единица | Проверка |
|---|---|---|
| Карта | SVG по подготовленным геометриям LAEA; цвет — числовое значение отдельного показателя | 89 кодов, конечные координаты, единица, период, явная заливка пропусков |
| Плиточная карта | Одна равная ячейка на территорию; тот же фильтр и шкала | Число объектов не меняется при смене представления |
| Динамика | SVG-линии по одному источнику и типу периода; разрывы при пропусках | Не соединять отсутствующие значения; не смешивать год и месяц |
| Прогноз | Сохранённые модельные точки, медиана и целевые значения | Не обозначать диагностический интервал как доказанный причинный эффект |
| Матрица мероприятий | Ячейка — сохранённая связь пары мероприятие/индикатор | 31 × 23; полные названия доступны при фокусе; отсутствие связи не равно отрицательному эффекту |
| Двудольная сеть | 54 узла и 70 связей; режим окрестности выбранного узла | Состав, типы линий, совпадение с таблицей; метрики относятся к исходному графу |
| Региональная сеть | Сохранённые 179 рёбер и 8 сообществ; новая фиксированная раскладка только для отображения | Геометрия раскладки не интерпретируется как географическое расстояние |
| PCA | Сохранённые координаты, нагрузки и объяснённая дисперсия | Координаты не подменяются пересчётом с другим набором данных |
| Финансовые графики | Линейная шкала расходов, единая единица и выбранный плановый период | Сумма долей, HHI, неаддитивные источники вынесены отдельно |
| Тексты | Словарные частоты и матрица сходства; полный контекст из корпуса | Ноль совпадений словаря не трактуется как отсутствие темы в политике |

Проверки отдельных визуальных слоёв выполнены локально при разработке: картография, сети, статистическая интерпретация и адаптивная компоновка. Новые независимые внешние экспертные аудиты не проводились. За образец общей ясности аналитических панелей использован пользовательский GeoTalent; его исходный интерфейс и фирменные активы не копировались. Новая цветовая система соответствует запросу на зелёно-жёлтую гамму.

## Компоновка и доступность

На широком экране используется постоянное левое меню, рабочая область и панели выбранного объекта. На мобильном меню выдвигается отдельно; закрытое меню исключено из клавиатурной навигации. При открытом меню фокус удерживается внутри, Escape закрывает его. Графики с длинными подписями получают горизонтальное прокручивание внутри панели, а не горизонтальный скролл всей страницы.

Наведению соответствует фокус клавиатуры; на карте также доступны выбор региона из списка и действия кнопками. Нулевые и отсутствующие значения различаются числом/штриховкой, а не только цветом. У SVG есть текстовые названия, у таблиц — заголовки; основные данные дублируются таблицей. Учтён `prefers-reduced-motion`. Полный сертификационный аудит WCAG не проводился.

## Производительность и экспорт

Карта содержит 89 объектов. Статистические ряды загружаются по источникам, таблицы используют пагинацию. На одной странице обычно открыты несколько графиков, а не все разделы одновременно. Сетевые представления по умолчанию показывают выбранную окрестность; полный граф включается явно. Нет фоновой анимации и непрерывного рендера.

SVG/PNG строятся из активной визуализации, с заголовком, источником и пояснениями шкалы. CSV отражает фильтр таблицы. JSON лаборатории содержит входы и параметры, необходимые для повторения. Экспортные файлы не меняют данные проекта.
