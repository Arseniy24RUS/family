# Экспертиза проекта Молодёжь и дети

## Авторский материал и редакции

Исходный отчёт сохранён без изменений в `public/downloads/projects/youth_children/report/expertise_youth_children_2026.docx`. Анализ охватывает сведения по состоянию на 27 октября 2026 года; статистический срез отчёта относится к 15 октября, документальный – к 19 октября. Даты последующих загрузок ЕМИСС не меняют дату авторской экспертизы.

Веб-версия включает 21 тематическую страницу. Все 303 содержательных блока исходного документа распределены по страницам однократно. Подписи и примечания присоединены к соответствующим таблицам и рисункам. Титульная часть, шаблон утверждения и исходное оглавление доступны в полном документе. Файл `report/coverage_manifest.json` связывает каждый исходный блок с его местом на сайте или в исходном документе.

В состав входят 12 таблиц, 17 исходных иллюстраций, 83 сноски и четыре формулы авторского отчёта. Дополнительно на странице лаборатории приведены две поясняющие расчётные формулы платформы. Оригинальные иллюстрации используются как источниковые материалы; интерактивные визуализации оформлены в принятой палитре проекта.

Точная сверка первичного источника выявила уточнение: в прозе отчёта цель получения нескольких квалификаций на 2028 и 2029 годы приведена как 15% и 21%. В выбранном паспорте Минобрнауки на странице 5 указаны 14,9% и 21,1%. Расчёты и интерактивная траектория используют точные паспортные значения. Авторский абзац сохранён и сопровождается отдельным пояснением. Копия выбранного паспорта находится в `documentary/national_passport_minobrnauki.pdf`; URL и SHA-256 сохранены в `targets.json`.

## Состав документальных данных

`public/data/projects/youth_children/documentary.json` содержит компактную структуру для интерфейса: плановое финансирование девяти федеральных проектов по шести годам, выбранные целевые траектории, сведения об источниках, 277 документальных узлов, 510 исходных связей, 434 связи результатов и показателей через общую задачу и 122 непроверенных лексических кандидата. Прямые паспортные связи отдельно представлены для десяти рассмотренных результатов: 31 ребро из трёх федеральных проектов.

В тематическом анализе сохранены все 18 категорий, 162 ячейки профилей девяти федеральных паспортов, 36 внутрипроектных пар косинусной близости и десять межпроектных сравнений до и после стемминга. Общий фиксированный корпус TF-IDF содержит 137 документов. Для интерпретации национального и федеральных паспортов используются десять структурированных электронных публикаций одного проекта; другие жанры имеют отдельные признаки происхождения.

Полный документальный набор находится в `public/downloads/projects/youth_children/documentary/documentary_full.json` и в исходных CSV. Он сохраняет 11 000 текстовых единиц и 12 187 контекстов KWIC. В интерфейсе документы подгружаются отдельно по индексу `text.documentFiles`; большой корпус не входит в начальную загрузку страницы обзора. Для всех 24 относящихся к проекту исходных HTML и PDF сохранены точные байты в `documentary_sources.zip` и реестр `source_index.json`.

## Финансовые единицы и проверка

Агрегирование использует только строки общего планового финансирования заголовков паспортов. Вложенные источники и межбюджетные перечисления не прибавляются повторно. Денежные суммы рассчитываются через Python `Decimal` в тысячах рублей, а затем переводятся в миллиарды.

Сумма девяти федеральных паспортов за 2025–2030 годы равна 6 181 320 505,53 тыс. руб.; национальный план равен 6 177 944 262,03 тыс. руб.; расхождение равно 3 376 243,50 тыс. руб. HHI равен 0,22357150656842767. Эти величины описывают паспортные планы в разных публичных редакциях и не характеризуют кассовое исполнение, бюджетную эффективность или перерасход.

## Воспроизведение

Обычная сборка документальных данных работает на стандартной библиотеке Python и не обращается в сеть:

```bash
python scripts/build_youth_documentary.py
```

Сжатый входной файл `documentary_inputs.json.gz` содержит фиксированные текстовые профили, параметры и словарь, исходные исследовательские строки и их контрольные суммы. Первоначальные исследовательские программы включены как материалы происхождения. Платформенный адаптер воспроизводит расчёт из компактного набора, поэтому полная многогигабайтная база исследования для этой операции не требуется.

Независимый пересчёт TF-IDF, 36 внутрипроектных пар, десяти межпроектных сравнений, 1 200 характерных терминов, 432 тематических ячеек и чувствительности к стеммингу выполняется отдельно:

```bash
python -m pip install -r requirements-youth-research.txt
python scripts/build_youth_documentary.py --verify-text
```

Словари или языковые модели из сети не загружаются. Стемминг выполняется локальным SnowballStemmer; это отдельная проверка чувствительности и не лемматизация. Результат независимого пересчёта записывается в `documentary/text_replication_validation.json` и не стирается обычной сборкой.

Полное извлечение исходного Word-документа и сборка содержательных страниц выполняются следующей командой:

```bash
python scripts/build_youth_expertise.py
```

Скрипт использует вложенный DOCX, распознаёт абзацы, таблицы, рисунки, сноски и формулы, сохраняет исходные иллюстрации и создаёт `expertise.json`. Проверенные номера страниц находятся в `inputs/youth/report/report_page_locations.json` и применяются только при совпадении SHA-256 исходного DOCX. Для иного документа необходимо обновить редакторскую разметку и проверить новый рендер; автоматическая подмена старых локаторов не допускается.

## Границы интерпретации

Два самостоятельных годовых факта разных показателей не образуют временной ряд для регрессионного прогноза. Расстояние до цели и среднее требуемое изменение являются арифметическими ориентирами. Два разновременных региональных среза не используются для общего рейтинга, PCA, кластеризации либо интегральной оценки проекта. Причинные эффекты не вычисляются без пригодного исследовательского дизайна.

Документальная связь, связь через общую задачу и лексический кандидат имеют разные классы доказательности. Прямое указание результата в паспорте не удостоверяет его исполнения. Неразрешённая связь вторичной электронной публикации не доказывает отсутствия связи в полном паспорте. Нулевая словарная частота не доказывает отсутствия соответствующей деятельности. Сходство текстов не измеряет качество или согласованность практической реализации.
