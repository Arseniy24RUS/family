# Передача накопительного выпуска 2.12.0-platform.1 в Codex App

Полный комплект продолжает `2.11.0-export.1`. Архивы предыдущих выпусков накладывать не требуется. Сохраняются все 12 проектов и их исследовательские материалы. Текущий выпуск обновляет документы, официальные логотипы и общую техническую реализацию.

Распакуйте ZIP в отдельную папку и выполните `python scripts/restore_package_copies.py --verify`. Сравните комплект с рабочей веткой `Arseniy24RUS/family`; сохраняйте историю Git, более поздние изменения пользователя, настройки публикации, секреты и расписания. Исходный commit в манифесте обозначает происхождение первоначального сайта и не считается текущей вершиной репозитория.

Перенесите изменения в отдельную ветку. В новой рабочей среде установите зависимости из `scripts/requirements-analytics.txt` полностью, вместе с транзитивными зависимостями. PDF уже подготовлены и входят в архив: для обычной сборки LibreOffice не нужен. Входные DOCX находятся в `inputs/revised_expertises/edition-2026-10-30`; их контрольные суммы не должны изменяться.

```bash
python -m pip install -r scripts/requirements-analytics.txt
npm test
python -m unittest discover -s tests -p 'test_*.py' -v
npm run build
npm run validate
npm run build:pages
python -m pip install -r scripts/requirements-browser.txt
python -m playwright install chromium
python tests/run_browser.py --directory .pages --output <каталог_проверок_вне_репозитория>
```

Проверьте открытие всех проектов, переключение официального логотипа в шапке, актуальные PDF, каталог `research/reports.html`, карты, калькуляторы и возврат браузером назад. «Об авторах» остаётся только у «Семьи». Мобильная панель проектов прокручивается; меню и ссылки на документы доступны на узком экране.

Общие модули интерфейса находятся в `src/platform/runtime.js`, `src/core/cache.js`, `src/core/data.js`, `src/platform/data.js` и `src/components/`. Проектные страницы сохраняют свои предметные расчёты. Новый проект нельзя добавлять только в визуальную панель: согласуйте реестр навигации, runtime и реестр текущих документов; валидаторы проверяют их полноту.

Полный `docs/` предназначен для локального просмотра. Команда `npm run build:pages` формирует компактную `.pages/` с проверкой размера и точного восстановления JSON. Существующие workflow публикуют `.pages/`. Не заменяйте полный исходный `public/` или `docs/` сжатой копией и не переносите временные каталоги QA в репозиторий.

Изменение интерфейса не означает обновления статистики. В этом выпуске внешняя загрузка ЕМИСС не выполнялась; сохранены даты и происхождение прежних наблюдений. Перед публичной публикацией учитывайте фактическое состояние репозитория и привычный порядок проверки изменений пользователем. Подготовка накопительного архива сама по себе не отправляет коммиты и не публикует сайт.

Объяснение решений: `PLATFORM_RELEASE_RU.md`. Проверка документов: `CURRENT_REPORTS_AUDIT.json`. Происхождение логотипов: `BRAND_LOGOS_RU.md` и `BRAND_LOGOS_PROVENANCE.json`. Схема компактной публикации: `PAGES_PUBLICATION_RU.md`.
