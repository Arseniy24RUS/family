# Проверка выпуска 1.2.0

## Изменения и область проверки

Обновлены общая тема, шапка и боковая навигация, цвета всех программно построенных графиков и карт, компоновка страницы прогнозов. Институциональные логотипы находятся в шапке, без видимых подписей, в порядке РАН → ФНИСЦ РАН → ИСД ФНИСЦ РАН. Изображения и ссылки сохранены, названия остаются в alt/aria-label.

Новая модель `monthly-nonlinear-ensemble/1.2.0` пересчитала 172 ряда на прежних наблюдениях. Расчёт включает гармоническую регрессию и квазипериодический GP с GLS-оценкой среднего. Отдельно проверены зависимость формы от входа, отсутствие искусственной волны на ровном ряду, разложение прогнозной точки и отсутствие будущих результатов в весах временной проверки.

## Проверка чисел и сохранности источников

Тест браузера сопоставляет каждую координату синей прогнозной линии с соответствующим числом JSON через одно и то же аффинное преобразование шкалы. Получено 58 точек: последнее наблюдение и 57 прогнозных месяцев. Путь SVG состоит из M/L-сегментов, без добавленного сплайна. В режиме 24 месяцев скачиваемый CSV содержит ровно показанные 24 расчётных значения.

Проверены положительность, порядок условных границ, сумма весов и равенство `value = trend_value * cycle_factor * local_factor`. В текущем срезе СКР3+ не превышает общий СКР ни в одной совместной прогнозной точке. Ограничение не обеспечивается скрытым обрезанием; проверка контролирует результат независимых расчётов.

Данные из `public/data/baseline/`, исходный отчёт, сохранённые прогнозы и исследовательские таблицы, а также исходные авторские скрипты побайтно сопоставлены с выпуском 1.1.0 и не изменены. Перечень проверенных файлов и фактические ошибки всех новых рядов приведены в `forecast_validation_1_2.json`.

Автономный `projections_python.zip` отдельно распакован вне проекта: повторены национальный СКР, московский СКР3+ и сохранённый сценарий передвижки с полным сравнением результатов. Кодовые ячейки Colab проверены компиляцией; запуск непосредственно в сервисе Google Colab не выполнялся.

## Ограничения

Более гибкая форма не гарантирует меньшую ошибку. По национальному СКР MAE нового ансамбля на 14 общих краткосрочных проверках выше, чем у сохранения уровня; по СКР3+ ниже. В интерфейсе опубликованы оба результата. Одного с небольшим годового цикла недостаточно для подтверждения устойчивой сезонности. Долгосрочная точность и фактическое покрытие 80/95%-полос не валидированы.

Живые запросы ЕМИСС, внешние возрастные книги, загрузка фотографий на стороне GitHub и сами workflows в этом выпуске не запускались. Реальные прогнозы численности не добавлены вместо отсутствующих входов. Сохранены прежние механизмы загрузки, проверки, отказа и локального импорта. Новая версия изменяет оформление и вычислительную модель показателей, а не дату исходных наблюдений.

## Команды повторения

```bash
python -m pip install -r scripts/requirements-refresh.txt
npm test
OPENBLAS_NUM_THREADS=1 python -m unittest discover -s tests -p 'test_*.py' -v
OPENBLAS_NUM_THREADS=1 python scripts/build_indicator_forecasts.py
npm run build
npm run validate
python tests/browser_check.py --virtual --browser /usr/bin/chromium --output /tmp/semya-base
python tests/browser_upgrade.py --virtual --browser /usr/bin/chromium --output /tmp/semya-upgrade
python tests/browser_redesign.py --output /tmp/semya-redesign
```

Для запуска браузерных тестов дополнительно нужен Playwright; в обычной среде первые два сценария можно направить на локальный HTTP-сервер без `--virtual`. Скрипты тестов не меняют архив исследования.
