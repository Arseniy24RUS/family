Метод: Картограмма и сопоставимый региональный срез

Число соединяется с полигоном региона по устойчивому коду. Цвет показывает величину, а не площадь региона и не оценку работы органов власти. Плиточное представление даёт территориям одинаковую площадь.

Схема метода

Статистический код региона ↔ код полигона; одна карта = один источник + один тип периода + одна дата

Для каких задач подходит

Полезно, когда важны соседство, территориальная концентрация и различия между регионами. Для точного чтения карта дополняется таблицей.

Исходные данные

ru_regions.geojson пользователя; подготовленные выгрузки ЕМИСС; справочник 89 территорий. Отсутствующие значения остаются на карте с отдельной заливкой.

Воспроизведение расчётов

GeoPandas.merge по коду региона; pyproj для проекции; matplotlib для статической карты. Здесь геометрия один раз переведена в равновеликую проекцию, затем интерактивно рисуется в SVG.

gdf = geopandas.read_file("ru_regions.geojson")
# Сначала проверьте таблицу соответствия кодов.
joined = gdf.merge(values, on="region_code", how="left")
joined.to_crs("+proj=laea +lat_0=62 +lon_0=100").plot(column="value")

Ограничения интерпретации

Статистические границы и подписи воспроизводят предоставленный исследовательский набор; карта не является утверждением о правовом статусе территорий. Наблюдения разных периодов и агрегаты с вложенными округами не суммируются.

Вывод авторов

Региональные профили показывают, что распределения рождаемости, бедности и охвата услугами не совпадают. Поэтому один показатель не описывает все условия жизни семьи.
