# Национальные проекты: исследовательская платформа

Накопительное обновление **2.12.0-platform.1**, 30 октября 2026 года. Основа: полный комплект `2.11.0-export.1`. Все двенадцать проектов платформы представлены полными исследованиями. Текущий выпуск обновляет авторские документы и общие компоненты платформы.

Платформа расширяет существующий сайт [нацпроекта «Семья»](https://github.com/Arseniy24RUS/family) до двенадцати проектов. «Новые технологии сбережения здоровья» добавлены к первоначальному перечню из одиннадцати. Сохраняются интерфейс «Семьи», её двадцать маршрутов, авторская экспертиза и прежние ссылки. В верхней панели можно выбрать другой нацпроект; на мобильных экранах список прокручивается по горизонтали.

## Актуальные экспертизы и единый интерфейс

Для всех 12 проектов опубликованы PDF и неизменённые DOCX авторской редакции от 30.10.2026. Общий каталог доступен по адресу `research/reports.html`; кнопка PDF присутствует на каждой интерактивной странице, а обзор и библиотека проекта содержат карточку актуального отчёта. В статических текстах используется тот же реестр документов. Прежние отчёты сохранены и подписаны как исходные документы расчётной версии.

Перед логотипами РАН, ФНИСЦ РАН и ИСД ФНИСЦ РАН размещён официальный векторный логотип выбранного нацпроекта. Все 12 файлов извлечены со страницы 47 предоставленного брендбука. Логотип и ссылка на обзор меняются при переключении проекта; прежние цветовые темы сохранены.

Общий загрузчик получает только код и оформление выбранного исследования. Данные «Семьи» загружаются при открытии её страниц; названия регионов вынесены в небольшой общий файл. Повторные запросы используют ограниченный кэш, ошибки допускают повторную загрузку. Компактная публикация сжимает статистические ряды и крупные JSON без изменения исходных байтов. Подробности выпуска: [PLATFORM_RELEASE_RU.md](documentation/PLATFORM_RELEASE_RU.md).

## Открыть готовый сайт

Архив содержит все ресурсы готового сайта. Побайтово одинаковые копии `docs/` упакованы один раз и автоматически восстанавливаются при первом запуске по `PACKAGE_COPIES.json`. Сеть и аналитический пересчёт для этого не нужны, достаточно Python 3.11 или новее. Уже существующие файлы не перезаписываются.

- Windows: запустите `start_local.bat`.
- macOS / Linux: выполните `bash start_local.sh`.
- Либо из папки проекта: `python scripts/preview_platform.py`.

Скрипт откроет `http://127.0.0.1:8080/`. Окно сервера нужно оставить открытым. Если порт занят, используйте `python scripts/preview_platform.py --port 8081`. Завершение: Ctrl+C.

Двойной щелчок по `docs/index.html` не заменяет HTTP-сервер: браузеру требуется HTTP для загрузки модулей, JSON и вычислительных воркеров. Файл `START_HERE.html` содержит короткую инструкцию.

## Публикация GitHub Pages

Полный каталог `docs/` используется для локального просмотра и проверки. Для GitHub Pages команда `npm run build:pages` создаёт отдельную публикационную копию `.pages/` с проверкой предела 1 ГБ. Статистические ряды и крупные JSON передаются в gzip и восстанавливаются побайтово в приложении; все исходники сохранены в полном комплекте. PDF, DOCX, CSV и остальные скачиваемые оригиналы доступны обычными файлами. Оба workflow автоматически строят и проверяют эту копию перед загрузкой. [Схема публикации и проверки](documentation/PAGES_PUBLICATION_RU.md).

Исследовательский источник: `NationalProjects_Analytics_1.2.0`, выпуск от 27.10.2026. Он содержит статистический срез **15.10.2026**, документальный корпус новых проектов от **19.10.2026**, а исходные авторские материалы «Семьи» сохраняют дату **14.05.2026**.

В исследовательской основе первоначальных одиннадцати проектов сохранены реестры 339 показателей и 429 записей применимости методов. Проект «Новые технологии сбережения здоровья» имеет собственный реестр 21 карточки и отдельный аудит пригодности методов. Последние национальные наблюдения отобраны только из текущих пригодных статистических снимков; единицы, периоды, категории и источники сохраняются. Реестр нового проекта может связывать показатель с несколькими источниками, измеряющими разные величины. Такие наблюдения показаны отдельно с собственными названиями.

## Разработка и проверка

Требуются Node.js 22 или новее и Python 3 с зависимостями аналитики:

```bash
python -m pip install -r scripts/requirements-analytics.txt
npm test
npm run build
npm run validate
python -m unittest discover -s tests -p "test_*.py"
```

Браузерные проверки используют Playwright и Chromium:

```bash
python -m pip install -r scripts/requirements-browser.txt
python -m playwright install chromium
npm run test:browser
```

Сборка пересчитывает документальные и статистические результаты одиннадцати добавленных полных исследований из включённых входных данных, создаёт `docs/`, статические страницы для поиска, реестры файлов и опубликованные авторские страницы. Она работает без сетевого запроса к ЕМИСС. Папка `public/` хранит исходные публикуемые ресурсы, `src/` – интерфейс, `scripts/` – воспроизводимые процедуры. Веб-приложению не требуются CDN и внешние библиотеки JavaScript во время работы.

Для отдельного обновления выполните `python scripts/refresh_youth_emiss.py`, затем сборку и проверку. Один источник: `python scripts/refresh_youth_emiss.py --source 62969`. В исходный комплект включены нормализованные наблюдения, первичные выгрузки, происхождение значений и воспроизводимый импорт `python scripts/import_youth_release.py --from-inputs`.

Для обновления «Кадров» выполните `python scripts/refresh_personnel_emiss.py`, затем сборку и проверку. Один источник: `python scripts/refresh_personnel_emiss.py --source 62884`. Первичные ответы, контракты методик, нормализованные данные и импорт из включённых входов сохраняются вместе с платформой.

Для обновления «Продолжительной и активной жизни» выполните `python scripts/refresh_longlife_emiss.py`, затем сборку и проверку. Один источник: `python scripts/refresh_longlife_emiss.py --source 62954`. Сохранённые первичные ответы включают SDMX, Excel и JSON. Успешность обновления определяется отдельно для каждого источника.
