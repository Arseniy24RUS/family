# Накопительный выпуск 2.3.0-longlife.1

Дата подготовки: 29 октября 2026 года. Основа: `2.2.0-personnel.1`. Проект нового раздела: `long_active_life` – «Продолжительная и активная жизнь».

Выпуск включает весь исходный код и готовую папку `docs/` для GitHub Pages. Четыре нацпроекта имеют полные тематические разделы: «Семья», «Молодёжь и дети», «Кадры», «Продолжительная и активная жизнь». У остальных семи сохранена исследовательская основа для последующего наполнения. Верхняя панель содержит все 11 проектов; на мобильном экране она прокручивается. Раздел «Об авторах» доступен только у «Семьи».

Для нового проекта сохранены заранее установленные официальный логотип, локальный шрифт Roboto и основной цвет `#D9124A`. Цвета «Семьи» и предыдущих разделов не меняются. Приложение использует единый режим последних проверенных данных. Отдельного пользовательского переключателя на архив экспертизы нет; даты авторского отчёта, документальных редакций и статистических наблюдений показываются раздельно.

## Что добавлено

Все 387 содержательных блоков приложенного авторского отчёта распределены по 21 странице. Сохранены 14 таблиц, 18 оригинальных рисунков, восемь восстановленных формул и 137 сносок. Реестр содержит 138 записей с учётом самого отчёта. Исходный DOCX опубликован без изменения байтов; доступен также полный Markdown. Карта покрытия связывает блоки исходного документа со страницами платформы и содержит проверенные указатели страниц.

Таблицы и диаграммы допускают выгрузку; диаграммы снабжены названием, единицей и источником. Полные статистические истории и текстовые контексты подгружаются по выбранному источнику или документу. При ошибке загрузки доступны повторная попытка и сохранённые фильтры. Глубокие ссылки сохраняют выбранную страницу и параметры.

## Статистическое наполнение

Реестр содержит 23 верхнеуровневые позиции без отдельного установленного кода ЕМИСС и 42 федеральные позиции с подтверждёнными числовыми источниками. Числа для верхнеуровневых позиций не подставляются автоматически из похожих федеральных показателей.

| Характеристика сохранённого среза | Количество |
|---|---:|
| Источники ЕМИСС с числовыми данными | 42 |
| Источники с региональными наблюдениями | 34 |
| Исходные статистические ячейки | 61 029 |
| Числовые значения | 57 391 |
| Пропуски | 3 638 |
| Числовые значения, пригодные для текущих расчётов | 57 337 |
| Значения обычных долей вне допустимой области, сохранённые с флагом | 54 |
| Самостоятельные годовые факты по Российской Федерации | 10 |
| Рабочие позиции целей на 2025–2030 годы | 390 |
| Числовые значения целей | 378 |

Каждая ячейка сохраняет исходный ключ наблюдения, источник, подпись и тип периода, единицу, первоначальное значение и причину аналитического исключения, если она есть. Пропуски не превращаются в нули. Декабрьская запись не объявляется годовой; опубликованные годовые и декабрьские значения показаны раздельно. Для накопительных показателей раскрыто окно измерения, а для сравнения изменений используется одинаковый месяц разных лет.

Ограничение 100% применяется только к обычным долям с соответствующим смыслом. Индекс временной нетрудоспособности относительно базы и использование расчётной мощности допускают значения выше 100. Общероссийское значение не заменяется средним региональных значений. Абсолютный прокси цифрового направления сохраняет собственные единицы и статус.

Кадровое сопоставление воспроизводит авторский срез июля 2026 года по 83 сопоставимым территориям. Из них 23 имеют оба кадровых показателя ниже опубликованных общероссийских уровней, ещё 23 – только обеспеченность врачами ниже уровня РФ, пять – только обеспеченность средним медперсоналом, 32 – оба показателя на уровне РФ или выше. Это диагностическое сравнение двух показателей, а не общий рейтинг качества здравоохранения.

Многомерная диагностика использует авторский срез сентября 2026 года: 83 территории, 29 признаков, пять исходных пропусков. Медианные подстановки выполняются только в отдельной диагностической копии; исходные пропуски сохранены. Первые две компоненты объясняют около 24,29% стандартизированной вариации. Слабое разделение кластеров и чувствительность к составу данных раскрыты на странице.

Для устойчивости к начальным состояниям сохранены две разные процедуры. Авторский отчёт указывает ARI примерно 0,905–1,000 для десяти запусков, не перечисляя их seed. Независимый аудит платформы использует явно заданные seed 0–9, `n_init=30` и базовый seed 42 и даёт диапазон −0,0016820150540347335–1,000. Новый диапазон не приписывается авторской процедуре и не выдаётся за её опровержение. Пояснение размещено рядом с сохранённым авторским материалом; матрицы, параметры и результаты запусков доступны для повторения.

## Документы, финансовые горизонты и возрастной контекст

Документальный корпус проекта содержит 15 документов: 12 HTML-паспортов и три PDF. Электронные страницы вторичного представления бюджетных паспортов обозначены как `secondary_epbs_rendering`. Редакции, даты сохранения, SHA-256 и указатели исходных фрагментов включены в данные. Для текущих целей выбирается целая серия одной редакции; все 961 строки альтернативных редакций доступны отдельно.

| Плановая величина | Значение, тыс. руб. |
|---|---:|
| Сумма 11 федеральных проектов за 2025–2030 | 4 066 231 073,60 |
| Национальный план за 2025–2030 | 4 136 479 588,77 |
| Разность «национальный план − сумма федеральных проектов» | 70 248 515,17 |
| Опубликованные федеральные назначения за 2031–2036 | 2 292 684 898,80 |
| Полный опубликованный федеральный горизонт | 6 358 915 972,40 |

Общий горизонт содержит 66 федеральных годовых ячеек. Полный опубликованный горизонт содержит 120: у девяти проектов представлены годы до 2036, у Д9 и ДА – до 2030. Отсутствие более поздних публикаций не обозначено нулевым финансированием. Все суммы и их сверка рассчитываются в точной десятичной арифметике. Это паспортные планы разных документов; они не измеряют кассовое исполнение, нарушение или величину достигнутого эффекта.

Матрица сердечно-сосудистого направления содержит четыре результата, шесть показателей и 24 проверенные привязки. Веса взяты из полного паспорта с планом реализации 2025 года; их сохранение в электронной редакции 2026 года отдельно не подтверждено. Веса не трактуются как оценённые причинные эффекты. Структура документов, связи через общую задачу и лексическое сходство имеют отдельные подписи и слои.

Возрастная таблица Росстата за 2023 год воспроизведена по индексированному тексту официального PDF. Сохранены 17 строк и 51 исходное число. Предварительная общероссийская точка 2024 года имеет отдельный источник: примечание на печатной странице 31 сборника Волгоградстата; отсутствующие значения по полу не придуманы. Исходные PDF не удалось получить целиком, поэтому SHA сохранённых текстовых фрагментов не выдаются за SHA этих PDF. Данные 2022 года сохранены как авторская транскрипция с собственным статусом проверки. Демографический контекст отделён от текущих рядов показателей проекта.

## Обновление ЕМИСС и воспроизводимость

Новый модуль поддерживает три реально встречающихся формата исходных выгрузок: SDMX, Excel и публичную таблицу JSON. Для всех 42 источников сохранены паспорт, контракт измерения и компактный входной ZIP. Обычная сборка работает без подключения многогигабайтной исследовательской базы и без запроса сети.

`refresh_longlife_emiss.py` проверяет источник до публикации новой версии. Ошибка сети, неполная таблица, изменение единицы, неоднозначность измерений или непригодный ответ не заменяют последний проверенный набор. Статус попытки и дата последнего успеха различаются. При повторной недоступности запросы остальных источников откладываются с явным статусом. Запись полных CSV выполняется атомарно.

В GitHub Actions добавлены новый проект, необязательный выбор одного его источника, публикация статуса и пересчёт производных таблиц. Существующий порядок подключения к источнику сохранён. Удалённый workflow в ходе подготовки архива не запускался; его работа в репозитории зависит от действующих настроек и секретов владельца. Подробный результат сетевой проверки выпуска зафиксирован в `LONGLIFE_VALIDATION.json` и `public/data/projects/long_active_life/refresh-status.json`.

Команды нового раздела:

```bash
python -m pip install -r scripts/requirements-analytics.txt
python scripts/import_longlife_release.py --from-inputs
python scripts/build_longlife_expertise.py
python scripts/build_longlife_documentary.py
python scripts/build_longlife_analytics.py
npm run build
npm run validate
```

Импорт `--from-inputs` восстанавливает включённый исследовательский срез и не является сетевым обновлением. Для получения новых публикаций используется `npm run refresh:longlife`; после него следует обычная сборка. Содержание датированного отчёта не переписывается автоматически вслед за изменением статистики.

## Проверка и использование архива

Машиночитаемый протокол `documentation/LONGLIFE_VALIDATION.json` фиксирует общие JavaScript- и Python-проверки, реальные браузерные сценарии по HTTP с префиксом `/family/`, сверку всех статистических ячеек с исходной базой, точную финансовую арифметику и сохранность предыдущих проектов. Проверяются настольные и мобильные страницы, фильтры, переходы, выгрузки CSV/SVG/PNG, карты, подгрузка источников и повторная попытка после ошибки.

Для локального просмотра распакуйте единый ZIP и откройте `START_HERE.html`. Интерактивный сайт следует запускать через HTTP; для Windows включён `start_local.bat` при установленном Python. Готовая папка `docs/` уже находится внутри архива. Инструкция переноса накопительных изменений через Codex – `CODEX_HANDOFF_RU.md`. Подготовка этого выпуска не изменяет удалённый репозиторий и не публикует сайт автоматически.

Подробности документальных расчётов – `LONGLIFE_DOCUMENTARY_RU.md`. Контракты статистики, форматы выгрузок, правила исключений и обновление – `LONGLIFE_DATA_AND_REFRESH_RU.md`.
