## Данные и содержательные ограничения

Включены 12 159 исходных числовых ячеек. Восемь нулевых значений квантовых показателей сохранены в первичных данных и исключены из аналитических расчётов до проверки. Другие содержательно допустимые нули сохраняются как числа. Индекс противодействия мошенничеству допускает значения выше 100. Единицы индекса и процентные пункты различаются.

Сорок четыре декабрьских сопоставления с паспортными целями имеют условный статус. В текущем комплекте нет подтверждённых самостоятельных годовых фактов, достаточных для формального вывода об исполнении цели. Месячная публикация может повторять годовое измерение. Официальное исполнение не определяется автоматически по такой записи. Два показателя с несовпадающими единицами исключены из сопоставления с планом.

Семь региональных профилей не объединяются в единый рейтинг. Федеральная запись не является сопоставимым средним регионов и показана отдельно. В пятипризнаковой матрице заполнен один пропуск Москвы по источнику 62815, медианой 76,835. Заполнение относится только к матрице модели. Исходные ряды, таблицы и карты сохраняют фактическое отсутствие записи.

Первые две главные компоненты описывают 51,39% вариации стандартизированной матрицы. Базовое разбиение содержит две группы из 36 и 49 регионов, силуэт равен 0,24374. При установленном минимальном размере группы только один из семи вариантов начального состояния и один из пяти вариантов исключения признака дают допустимое выбранное разбиение. Проверки указывают на ограниченную устойчивость групп. Частота отметки Isolation Forest при семи запусках представляет алгоритмическую характеристику, без вероятностной интерпретации риска региона.

Паспортный план НП и сумма девяти ФП за 2025–2030 годы точно совпадают: 1 212 749 112,29 тыс. руб. Отдельные обязательства Ц4 за 2031–2036 годы составляют 5 708 673,00 тыс. руб. Отсутствующая строка Ц1 за 2030 год остаётся пропуском. Подробности документальной арифметики и оснований сравнения раскрыты в `DATAECONOMY_DOCUMENTARY_RU.md`.

## Даты и обновление

Статистический срез получен 15 октября 2026 года. Реальная попытка прямого обновления 29 октября 2026 года в 20:49:25 МСК завершилась тремя ошибками разрешения адреса. Остальные 45 источников были отложены. Новые наблюдения не получены, 96 файлов рядов и происхождения сохранены без изменений. Дата попытки отображается отдельно от даты источника.

Сборка и расчёты работают по включённым входным данным. Обновление ЕМИСС подключено к существующему GitHub Actions workflow с отдельными параметром `dataeconomy_source`, результатом `dataeconomy_state` и диагностикой. Правила описаны в `DATAECONOMY_DATA_AND_REFRESH_RU.md`.

## Проверка и передача

Протокол `DATAECONOMY_VALIDATION.json` фиксирует фактически выполненные проверки. Независимая перепись источников находится в `DATAECONOMY_SOURCE_AUDIT.json`, документальная перепись – в `DATAECONOMY_DOCUMENTARY_AUDIT.json`. Арифметика стандартизации, PCA, силуэта, ARI и геометрии временного сравнения дополнительно проверяется JavaScript-валидатором без использования аналитического кода Python.

Единый ZIP содержит полный накопительный комплект. Одинаковые копии готового сайта восстанавливаются по `PACKAGE_COPIES.json` из включённых файлов. Перед переносом в репозиторий выполните `python scripts/restore_package_copies.py --verify`. Сравнение с выпуском 2.7, контрольные суммы, проверка чистой распаковки и просмотр по HTTP входят в процедуру передачи. Публикация сайта и отправка коммитов в подготовку архива не входят.
