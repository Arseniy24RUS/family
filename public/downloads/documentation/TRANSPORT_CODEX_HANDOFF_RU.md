# Перенос транспортной экспертизы в Codex App

Накопительный комплект `2.10.0-transport.1` продолжает выпуск `2.9.0-tourism.1` и содержит все прежние материалы. Сравните его с текущей веткой `Arseniy24RUS/family`, сохраняя историю Git и последующие изменения пользователя. Коммит `50ad21c1ad1c94e3cf07857363333df120558617` обозначает происхождение исходного сайта, его актуальность в репозитории при подготовке этого выпуска повторно не проверялась.

## Перенос и проверка содержания

Распакуйте ZIP в отдельную папку. Выполните `python scripts/restore_package_copies.py --verify` перед сравнением и переносом. `RELEASE_MANIFEST.json` задаёт полный состав и контрольные суммы. `PACKAGE_COPIES.json` описывает побайтово одинаковые копии, чьи исходники физически включены в архив. Старые накопительные ZIP поверх нового комплекта накладывать не требуется.

Откройте `#/projects/efficient_transport/overview` и все 21 маршрута. Проверьте выбор каждого из 22 источников, периодов, категорий, 22 плановых траекторий и девяти федеральных направлений. Общие национальные показатели должны быть доступны в соответствующих направлениях Т2, Т6 и Т8. Проверьте полный авторский текст, формулы, таблицы, иллюстрации и ссылки `research/projects/efficient_transport/`.

Проверьте сохранение 442 чисел и 21 пропуска исходного среза. В источнике `62822` нет цели 2025 года, `62823` имеет допустимые нулевые приросты. Месячные кадровые записи `63268` и `63269` не должны обозначаться результатом текущего отчётного года. Индексы мощности и эффективности могут превышать 100, индексы с фиксированным знаменателем не заменяют текущую долю. Накопленные перевозки внутри каждого календарного года имеют отдельные линии.

По ЕМИСС региональных рядов нет. Региональный рейтинг не создаётся. Раздел географии использует авторские сведения о бассейнах, коридорах, СМП и авиации. Для морских бассейнов проверьте переключение 2024/2025/изменение и соответствие таблице 6 доклада.

Проверьте четыре финансовых представления, три основания документальных связей, поиск по десяти паспортам, чувствительность текстовой процедуры и скачивание CSV. В лексической сети 36 пар охватывают 17 результатов. Различие между 15 показателями текущего детерминированного отбора и 16 в авторском тексте должно оставаться видимым вместе с объяснением равных коэффициентов. Неопределённые адресаты 42 ссылочных утверждений не должны получать вымышленные связи.

Проверьте шесть калькуляторов на пустых полях, допустимых значениях и недопустимых знаменателях. В расчёте эффективности инвестиций знаменатель относится ко всем федеральным инвестиционным мероприятиям данного национального проекта за тот же период. В цифровом индексе сохраняется фиксированный знаменатель 5 млрд документов 2030 года. Условные расчёты не должны обозначаться прогнозами или установленными эффектами.

Сохраните палитры прежних проектов и тему транспорта `#DCAA44`. Проверьте верхнюю панель на широком и узком экранах. Старые маршруты «Семьи», включая `#/authors`, должны работать. У остальных проектов раздел авторов отсутствует. При переключении нацпроекта общая смысловая страница сохраняется, чужие фильтры очищаются.

## Команды

```bash
python scripts/restore_package_copies.py --verify
python -m pip install -r scripts/requirements-analytics.txt
npm test
npm run build
npm run validate
npm run build:pages
python -m unittest discover -s tests -p "test_*.py"
```

Для браузерной проверки компактной публикации установите зависимости из `scripts/requirements-browser.txt` и Chromium согласно инструкции проекта. Выполните `python tests/run_browser.py --directory .pages --suite browser_transport --output <каталог_вне_репозитория>`. Полный запуск `tests/run_browser.py` содержит также сценарии прежних проектов. Проверяется HTTP с префиксом `/family/`, как в GitHub Pages. Границы проверки данного архива зафиксированы в `TRANSPORT_VALIDATION_RU.md`.

Локальный просмотр готового комплекта: `start_local.bat` в Windows или `bash start_local.sh` в macOS/Linux. Требуется Python 3.11 или новее. После запуска откройте `http://127.0.0.1:8080/#/projects/efficient_transport/overview`. Прямое открытие HTML с диска не обеспечивает загрузку модулей и данных по HTTP.

## Обновление и публикация

Для сетевого обновления используется `python scripts/refresh_transport_emiss.py`, параметр ручного workflow – `transport_source`, результат задания – `transport_state`. Обычная сборка не импортирует старый архив поверх более поздних рядов. Команда `import_transport_release.py --from-inputs` предназначена только для явного восстановления исходного среза.

Существующий маршрут доступа к ЕМИСС, расписание, секреты и настройки GitHub Pages сохраните. Секреты в комплект не входят. Проверенный полный каталог `docs/` служит входом для `.pages/`, которая проходит отдельную проверку размера и точного восстановления JSON. Оба workflow публикуют `.pages/`.
