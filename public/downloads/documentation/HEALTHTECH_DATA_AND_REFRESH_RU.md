# Статистика и обновление проекта «Новые технологии сбережения здоровья»

Документ относится к накопительному выпуску `2.4.0-healthtech.1` от 29 октября 2026 года. Идентификатор проекта в платформе – `health_technologies`. Сохранённая официальная иерархия ЕМИСС относит его к коду С. В первоначальном исследовательском архиве проект имел техническую категорию `excluded_С`, поскольку технологические нацпроекты находились за пределами прежних 11 разделов. Исходная категория сохранена в происхождении данных. Новый раздел добавлен к существующим проектам.

## Состав и происхождение данных

Официальный каталог, сохранённый 15 октября 2026 года, содержит 21 карточку нового проекта и 20 прямых ссылок на числовые источники ЕМИСС. Для карточки доли российских медицинских изделий в общем объёме рынка ссылка на отдельный числовой источник отсутствует. Код для неё не подбирался по сходству названий.

Для 14 источников 29 октября 2026 года получены открытые републикации Национального центра социально-экономических данных. Каждый комплект содержит описание набора через публичный API репозитория, CSV и оригинальный XLS с листами «Данные» и «Паспорт». Все исходные ячейки CSV сверены с соответствующими ячейками XLS. Контрольные суммы, адрес ресурса, время получения и указатель вида `Данные!D16` сохранены. Проверка подтверждает содержание полученных файлов. Актуальность текущей версии оригинала ЕМИСС непосредственно не подтверждена.

Ещё 127 числовых ячеек имеют ограничения, препятствующие их использованию в таких расчётах. Большую часть составляют месячные нули годовых показателей. Исключение из расчёта не удаляет число из таблицы, CSV или исходного файла.

Все наблюдения относятся к Российской Федерации. Региональные значения, географические сравнения, PCA, кластеризация и индексы пространственной автокорреляции по этому набору не вычисляются. Отсутствие открытого ряда С3–С5 не доказывает отсутствие ведомственного учёта или результата соответствующей меры.

Источники: [официальный каталог ЕМИСС](https://fedstat.ru/organizations/), [пример карточки ЕМИСС № 62986](https://fedstat.ru/indicator/62986), [републикация № 62986](https://repository.nsedc.ru/dataset/emiss_62986). Ссылки на остальные источники доступны в реестре и файлах происхождения. При использовании републикованных файлов сохраняется указание ЕМИСС, Минздрава России и Национального центра социально-экономических данных. Условия лицензирования из каталога репозитория включены в описание происхождения.

## Даты и период наблюдения

Дата получения файлов – 29 октября 2026 года. Дата нормативной и документальной базы авторской экспертизы – 28 октября 2026 года. Последнее обновление данных в сохранённых паспортах XLS датировано 20 или 22 января, 8 или 10 сентября 2026 года. Большинство месячных рядов завершается числом за август 2026 года, два квартальных ряда содержат значения за 2025 год.

Поля даты репозитория могут отличаться от даты во встроенном паспорте. Например, `dataset_update` для № 62986 указывает 13 февраля 2026 года, тогда как XLS содержит 8 сентября 2026 года. В платформе дата обновления статистики берётся из листа «Паспорт». Дата получения и дата изменения метаданных репозитория представлены отдельно. Новая проверка доступности не изменяет дату статистического содержания.

`published_at` первоначального пакета означает дату обновления исходных данных, прочитанную из XLS. При успешной будущей прямой проверке `acquired_at` и `verified_at` отражают время получения и проверки. Если исходная страница не позволяет однозначно извлечь собственную дату обновления, `published_at` остаётся неизвестной с пояснением `source_update_date_unavailable`. Время обращения не подставляется вместо даты источника.

## Файлы и воспроизводимость

`public/data/projects/health_technologies/indicators.json` содержит 21 позицию каталога. `statistics.json` содержит сводку, реестр и источники. Полная последовательность ячеек каждого источника находится в `series/<id>.json`, происхождение – в `provenance/<id>.json`. `analytics.json` содержит годовое сопоставление с планом, аудит годовой и декабрьской записей, сопоставимые изменения, условную проверку коммерциализации и ограничения методов. `methods.json` содержит предметные статусы применимости.

В наблюдении сохраняются исходный ключ, значение, строковое представление, тип и подпись периода, единица, территория, координата ячейки, аналитическое значение и объяснение исключения. `analytical_value: null` не заменяет исходное число. Пара полей `latest_published` и `latest_analytically_usable` различает последнюю числовую ячейку и последнее пригодное наблюдение. Основное отображаемое наблюдение сначала выбирает пригодное значение, затем период с интерпретируемой частотой. Исходные более поздние ячейки остаются доступными.

Опубликованные входные ZIP находятся в `public/downloads/projects/health_technologies/statistics/inputs/`. Файл `<id>.zip` включает исходные CSV.gz и XLS.zip, описание набора и журнал получения. `registry.zip` включает выбранные позиции и связи каталога, полный сохранённый HTML каталога в gzip и журнал получения всех 20 потенциальных публикаций. Воспроизведение не требует внешней многогигабайтной базы исследования.

Обычная автономная сборка производных представлений:

```bash
python scripts/build_healthtech_analytics.py
```

Воспроизведение первоначального среза из опубликованных входных пакетов в отдельной рабочей копии:

```bash
python scripts/import_healthtech_release.py --from-bundles --root /path/to/replay-copy
python scripts/build_healthtech_analytics.py --root /path/to/replay-copy
```

Команда импорта восстанавливает первоначальный срез и его исходные статусы. Она предназначена для воспроизведения в отдельной копии. Обычная сборка после обновления её не запускает и сохраняет актуальные проверенные пакеты. Поддерживается также первоначальный импорт из `inputs/healthtech_statistics` с флагом `--from-inputs`.

## Прямое обновление ЕМИСС

```bash
python scripts/refresh_healthtech_emiss.py
python scripts/refresh_healthtech_emiss.py --source 62986
python scripts/refresh_healthtech_emiss.py --timeout 8 --retries 0 --max-failures 3 --strict
```

Скрипт использует существующий адаптер формы выгрузки ЕМИСС с учётом однократного токена. Подтверждённый формат XLS проверен на всех 14 полученных оригинальных книгах. Адаптер проверяет название, единицу, методику, измерения, территорию, периоды, дубликаты и полноту ранее опубликованных периодов. При изменении единицы или методики публикация останавливается до предметной проверки контракта. Новые территориальные разрезы не присоединяются автоматически к национальному ряду.

Ошибка доступа, пустой ответ, исчезновение годового факта или потеря ранее опубликованного периода не заменяют сохранённые данные. Все проверки предшествуют записи нового пакета. После успешной проверки сохраняются исходный ответ, метаданные запроса без токенов, новые строки и пересмотры. Журнал различает первое появление наблюдения и пересмотр существующего значения. Для шести источников без восстановленной числовой публикации применяется режим проверки карточки: автоматическая публикация требует отдельного утверждения единицы, методики и структуры выгрузки. У двадцать первой карточки нет подтверждённого кода источника.

Регламент исправления единицы № 62985 предполагает получение новой официальной редакции, сохранение её исходных файлов, проверку названия, единицы и определения, затем отдельное изменение `scripts/healthtech_emiss_sources.json` и предметного правила в `healthtech_data.py`. Прежняя публикация остаётся в исходном ZIP. Сравнения с планом разрешаются после подтверждения совместимости определения и единицы. Простое переименование «процент» в «единицу» без источника не предусмотрено.

Результат последнего прямого запуска сохранён в `refresh-status.json` и `monitoring/healthtech_last_refresh.json`. Проверка 29 октября 2026 года в 14:25:16 по Москве завершилась тремя ошибками разрешения сетевого имени в среде выполнения адаптера. После них 17 запросов были отложены. Число успешных прямых публикаций равно нулю. Отложенные источники не отмечены проверенными. Ранее отдельное обращение к официальной карточке № 62986 вернуло HTTP 403. Сведений недостаточно для вывода о глобальной недоступности ЕМИСС.

Статусы уровня запуска – `success`, `partial`, `failed`. Источники могут иметь статусы `updated`, `unchanged`, `failed`, `deferred_after_source_outage`, `metadata_only`, `metadata_requires_contract_review`, `retained_republication`, `not_recovered`. Успешное чтение карточки не приравнивается к публикации числового набора. Даты прежней статистической публикации и последнее успешное обновление сохраняются при ошибке.

Общий workflow GitHub Actions вызывает скрипт в изолированной рабочей копии, собирает и проверяет результат, затем публикует принятые статические файлы. GitHub Pages обслуживает готовые данные. Посетитель сайта не выполняет прямой запрос к ЕМИСС. Запуск workflow в удалённом репозитории при подготовке этого выпуска не выполнялся.

## Проверка реализации

Автономное воспроизведение из опубликованных пакетов проверено в копии без каталога `inputs`. Проверена сохранность файлов при ошибке, работа ограничителя повторных ошибок, выбор одного источника, отказ от пустой выгрузки, регистрация пересмотра значения, запрет новой территории, неверной единицы и числового будущего периода. Контроль первоначальных 233 ячеек привязан к неизменным входным файлам. Будущее подтверждённое обновление может менять рабочие данные, сохраняя контракты и происхождение.

Тесты статистического модуля находятся в `tests/test_healthtech_data.py`. Общая приёмка интерфейса, ссылок, выгрузок и сохранности ранее готовых проектов выполняется отдельно при сборке накопительного выпуска.
