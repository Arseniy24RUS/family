# «Продолжительная и активная жизнь»: данные и обновление

Статистический модуль проекта `long_active_life` использует собственные проверенные публикации ЕМИСС из исследовательского выпуска 1.2.0. Он сохраняет исходные числа, пропуски, нули, периоды и территориальные подписи, отделяет годовые факты от оперативного наблюдения и воспроизводит статистические расчёты авторской экспертизы. Полная исследовательская база для сборки и последующего обновления не нужна.

## Разные формы процента

Общий фильтр «любой процент должен быть от 0 до 100» неприменим ко всем показателям проекта. Проверка использует содержательный контракт конкретного ряда.

| Источники | Предметный диапазон | Основание |
|---|---|---|
| 63006 | Неотрицательное отношение без потолка 100 | Накопленные дни нетрудоспособности на 100 работающих относительно одинакового периода 2023 года |
| 62926 | Неотрицательное отношение без потолка 100 | Использование расчётной пропускной способности передвижных подразделений |
| 62950, 62955 | Публикуемый прирост от −100, без верхнего потолка | Изменение относительно базового контингента; числа не обрезаются на 0 или 100 |
| 62970, 62971 | Неотрицательный коэффициент, без потолка 100 | Физические лица медицинского персонала на 10 тыс. населения |
| 63151 | Неотрицательное абсолютное число | Прокси-показатель наблюдаемых пациентов |
| 63005 | Неотрицательный объём | Литры этанола на человека за скользящие 12 месяцев |
| 62972 | Индекс остаточного дефицита, 0–100 | Текущий положительный кадровый разрыв относительно максимального базового разрыва |
| Остальные подтверждённые доли | 0–100 | Ограниченная доля соответствующей наблюдаемой совокупности |

Краткие описания 62950 и 62955 говорят об отношении, но полностью не раскрывают преобразование к публикуемому приросту. Поэтому соответствующие значения сопровождаются `growth_formula_requires_components`, без самостоятельно придуманной поправки формулы. Пример 1084,5 по реабилитации в Еврейской автономной области за сентябрь 2026 года сохраняется в исходном масштабе; он не объявляется ошибкой только из-за величины.

54 нарушения ограниченных долей распределены так: 62941 — 41, 62940 — 6, 62930 — 4, 62943, 62965 и 62914 — по одному. Поле `value` сохраняет опубликованное число; `analytical_value` для такой записи равно `null`, а причина находится в `quality_flags`. Эти числа видны в аудите и экспорте. Обычный ноль остаётся числом и не заменяется пропуском. Компоненты процента и размер контингента необходимы для содержательной интерпретации нулевого результата.

Направленность `lower`/`higher` описывает паспортный индикатор. Она не является клиническим правилом выбора лечения. Например, доля тромбэкстракции рассчитана относительно стационарного контингента, а не только пациентов с показаниями. Больничная летальность не равна коэффициенту смертности населения. Доля онкологических пациентов с диагнозом давностью пять лет и более описывает состав текущего регистра, а не пятилетнюю когортную выживаемость.

## Периоды и годовые значения

Исходная `frequency`, `period_start`, `period_end` и подпись периода сохраняются. Предметная конструкция дополнительно описана полями `period_semantics` и `measurement_window_start/end`.

- Для 63006 и 62930 отмечено накопление с начала года. Сентябрь сравнивается с сентябрём, а январское изменение не объявляется внезапным изменением качества помощи.
- У 63005 каждый месяц охватывает последние 12 календарных месяцев. Сентябрь 2026 года соответствует окну октябрь 2025 — сентябрь 2026. Соседние оценки пересекаются; их нельзя суммировать в годовой объём.
- Кадровые коэффициенты и число наблюдаемых пациентов характеризуют состояние контингента на дату.
- Для остальных оперативных рядов независимость соседних месяцев не предполагается без компонентных данных и подробного регламента.

Скользящее окно алкоголя подтверждено сохранённым описанием [ЕМИСС 63005](https://www.fedstat.ru/indicator/63005) и методикой Минздрава, опубликованной в [официальном разделе Росстата](https://rosstat.gov.ru/storage/mediabank/MET_N_031005.pdf). Перечень методик направления «Здоровье для каждого» размещён [здесь](https://rosstat.gov.ru/storage/mediabank/FP0310_N.htm). Прямой повторный доступ к этим страницам при подготовке был ограничен; сохранённые исходные карточки включены в проверенные ZIP.

У 11 источников имеются годовые позиции, но общероссийское значение 62950 за 2025 год отсутствует. Поэтому числовых годовых фактов десять. Неподтверждённая эквивалентность декабря году не вводится. Годовые и декабрьские записи имеют разные идентификаторы, даже если совпадают дата окончания и число.

Особенно существенны две пары:

| Источник | Декабрь 2025 | Самостоятельный годовой факт 2025 |
|---|---:|---:|
| 62957, полнота наблюдения при диабете | 40,4% | 70,8% |
| 62959, непрерывный мониторинг глюкозы | 97,8% | 81,0% |

Обе формы опубликованы и сохранены. Различные регламенты годового и оперативного расчёта не позволяют объявить одну из цифр ошибкой без согласования числителя, знаменателя и охвата организаций. Определение 62959 относится к правомочным детям и беременным женщинам; редакционная согласованность с паспортной формулой отмечена отдельно.

Последний числовой факт 62945 в исходном срезе — 67,6% за март 2026 года. Более поздние пустые позиции не получают это значение по инерции. Для каждого источника интерфейс показывает собственный период и загрузку выбранного ряда.

## Паспортные цели

`targets.json` содержит 65 строк × 6 лет, 378 числовых значений и 12 пропусков выбранных документальных серий. Документальный модуль сохраняет альтернативные редакции, исходные страницы, контрольные суммы и основания выбора. Статистика не смешивает значения разных редакций в одну траекторию.

На исходном срезе получены 79 арифметических сопоставлений, включая десять по самостоятельным годовым фактам. Остальные помечены `operational_point_vs_annual_plan`. Во всех строках `formal_attainment_eligible=false`: сопоставление с опубликованной редакцией октября 2026 года не удостоверяет исполнение первоначального обязательства 2025 года и не устанавливает причинный эффект.

62972 характеризует остаточный дефицит, поэтому меньшая величина соответствует благоприятному направлению. 63006 — уровень относительно базы: 85,1 означает на 14,9% ниже базы, а не сокращение на 85,1%. Разности индексов обозначаются пунктами индекса; разности ограниченных процентных долей — процентными пунктами. Официальная единица кадровых источников «человек» сохранена, а `display_unit` раскрывает коэффициент на 10 тыс. населения.

63151 допускает только собственное абсолютное прокси-сопоставление с целью 27 190 769 человек за 2025 год. Оно помечено `proxy_only=true` и не подменяет процентную цель цифрового мониторинга. Проценты и абсолютные числа не соединяются. Для условного сценария 2030 года нужны самостоятельная годовая база и документированная цель; вероятностный прогноз и доверительные интервалы не заявляются.

## Карта и кадровая совокупность

Карта использует собственные региональные ряды проекта. Наборы безработицы из «Кадров» и материалы других проектов не подставляются. Любой срез определяется одновременно источником, частотой, конечной датой и дополнительной категорией. Год и декабрь на 31 декабря остаются разными срезами. Индивидуальные последние значения разных регионов не собираются в одну условно современную карту.

Официальное измерение «ОКАТО (межведомственный)» распознано как география, а не дополнительная аналитическая категория. Оно сохранено в `source_geography_dimensions`; полный исходный `dimensions_json` есть во входном ZIP. Явные `field_overrides` фиксируют подтверждённые ID осей без угадывания позиции столбца.

Карта различает числовое покрытие источника и покрытие с подтверждённым соответствием геометрии. Если одному коду карты соответствуют неоднозначный областной агрегат и явно выделенная область без автономного округа, выбирается подтверждённый отдельный вариант независимо от порядка строк. Его пропуск не заполняется значением агрегата. Все исходные варианты остаются в таблице карты, CSV и проводнике данных. Неоднозначные агрегаты исключаются из окраски, квартилей и парных сравнений; их исходное число доступно с пояснением. Так, для 62930 за сентябрь 2026 сохраняется значение 49 по Архангельской области без Ненецкого округа и 85 сопоставимых числовых территорий. Для кадровых источников июля 2026 показаны 85 числовых территорий источника и 83 сопоставимых территории карты.

Авторское кадровое сравнение находится в `analytics.author_staffing`: июль 2026 года, 62971 и 62970, 83 территории. Две областные строки, Архангельская и Тюменская, исключены из этой совокупности из-за неоднозначного охвата автономных округов; сами округа сохранены отдельно. Исходные областные числа доступны в полных рядах. Ещё четыре позиции геометрии не имеют кадровых значений.

Из опубликованных общероссийских строк взяты 43,54 врача и 86,10 работника среднего персонала на 10 тыс. населения. Распределение территорий: оба коэффициента ниже РФ — 23, ниже только врачебный — 23, ниже только средний персонал — 5, оба не ниже — 32. Спирмен — 0,5555526402863961. Квартили рассчитаны линейной интерполяцией Hyndman–Fan type 7 без весов населения. Уровень РФ является описательным ориентиром; простое среднее региональных коэффициентов не используется вместо него.

## Многомерная диагностика и проверка устойчивости

Сентябрьский анализ хранится в `analytics.multivariate`. В исходной воспроизведённой совокупности 83 территории и 29 признаков; пять пропусков Москвы относятся к 62963, 62964, 62965, 63006 и 63039. Они заменены медианами только в отдельной диагностической копии. В `series/`, фактических CSV и картах исходные пропуски остаются `null`.

Стандартизация использует среднее и стандартное отклонение с `ddof=0`. PCA рассчитана полным SVD. Первая и вторая компоненты объясняют соответственно 15,454722% и 8,834015% вариации. Базовая k-means использует все 29 стандартизированных признаков, `random_state=42`, `n_init=30`; размеры групп — 43 и 40, силуэт — 0,0667196733. При k=3…6 возникают группы меньше пяти территорий. Полные случаи без Москвы дают 81 и 1 территорию; одиночная — Еврейская автономная область, силуэт 0,5290811445. Удаление реабилитации даёт 0,0684673989 и ARI=1 относительно базового разделения. Эти результаты не подтверждают универсальный рейтинг или устойчивую управленческую типологию.

### Два разных основания проверки начальных состояний

Авторский текст указывает ARI 0,905–1,000 для десяти вариантов, но не содержит их списка. В общей исследовательской базе найден другой расчёт: матрица 84×29, 12 замен, семь seed `[0, 1, 7, 21, 42, 99, 2026]` и отсутствие принятого базового разделения. Он не устанавливает десять состояний авторской процедуры 83×29. Семь строк сохранены в `statistical/research/legacy_cluster_seed_runs_1_2_0.csv`, происхождение и контрольные суммы — в `provenance/seed-audit-origin.json`.

Платформа отдельно публикует воспроизводимую дополнительную проверку **seed 0…9**, `n_init=30`. Её ARI находится между −0,0016820150540347335 и 1. Это иной, явно заданный набор запусков; состояния не подбирались ради совпадения с авторским диапазоном. Оригинальный текст сохранён, а различие процедур объяснено на странице методов. Все десять результатов доступны в `multivariate_seed_audit_2026_09.csv`.

JSON содержит SHA-256 исходной и диагностической CSV-матриц, идентификаторы снимков 29 источников, контрольную сумму скрипта и версии NumPy, SciPy и scikit-learn. Опубликованы исходная матрица, отдельная матрица с заменами, перечень замен, координаты PCA и нагрузки. Независимый тест пересчитывает доли дисперсии через собственные значения матрицы стандартизированных признаков; значения совпадают с PCA в пределах численной точности.

## Компактные загрузки и происхождение

`statistics.json` содержит краткие сведения об источниках, национальные ряды и согласованный последний региональный срез. Его размер в данном выпуске — около 2,48 МБ. `regional_history=[]` вместе с `regional_history_deferred=true` означает отложенную загрузку, а не отсутствие данных. Полный ряд загружается по `source.downloads.observations`; файл содержит `source_id` и `observations[]`. Поэтому начальная загрузка сайта не требует передачи всех подробных 61 тыс. записей.

В `statistical/emiss_inputs/{id}.zip` находятся нормализуемый `input.json`, оригинальные HTML, SDMX, XLS или grid JSON, параметры запроса и контрольные суммы. Все 42 входных ZIP вместе занимают около 6,7 МБ. SHA исходного содержимого gzip проверяется после распаковки; дополнительные `evidence_files` проверяют сохранённые байты каждого файла внутри ZIP. Воспроизведение не требует чтения рисунков отчёта.

`provenance/{id}.json` связывает опубликованный ряд, исходный ZIP, снимок, URL, время получения и SHA. Для успешного нового ответа создаётся `statistical/emiss_current/{id}.zip` с реальной выгрузкой и обезличенными метаданными без cookies и сеансовых токенов. CSV публикуются атомарной заменой завершённого файла, чтобы читатель не получил оборванный экспорт.

## Обновление из ЕМИСС

Серверный скрипт запускается через существующий GitHub workflow; браузер GitHub Pages читает подготовленные данные. Для каждого источника используется подтверждённый формат: два SDMX, 27 XLS и 13 JSON-таблиц. Выбор формата не является способом обхода запрета доступа. После сетевой ошибки коннектор не переходит к неограниченному перебору транспортов.

Проверяются ID и название показателя, методическое описание, единица, подтверждённые оси, все дополнительные измерения, территория, однозначность периода, завершённость числового периода, конечность числа, дубликаты и минимальное территориальное покрытие. XLS-парсер сверяет оси с метаданными и отвергает неоднозначное размещение. Grid-парсер сверяет объявленное число строк и коды всех измерений. Изменение единицы или методики сохраняет прежнюю опубликованную версию и требует содержательной проверки.

При сбое сохраняется последний проверенный ряд. Пустой экспорт не стирает числа; новая пустая ячейка не заменяет ранее подтверждённое значение. Новые наблюдения и пересмотр одной и той же ячейки учитываются отдельно. Проверка только метаданных не обновляет дату числового среза. После трёх последовательных транспортных ошибок остальные запросы откладываются и не обозначаются проверенными.

Во время подготовки 29.10.2026 выполнена одна прямая сетевая проверка с разрешением на сетевой доступ вне обычного sandbox, таймаутом 8 секунд и без повторов. Три первых источника получили DNS-ошибку данной среды, остальные 39 были отложены. Это не доказывает недоступность ЕМИСС. Числовые данные от 15.10.2026 сохранены. Точные времена и результаты находятся в `refresh-status.json` и `monitoring/longlife_last_refresh.json`; статус публикации сайта отделён от результата обновления источников.

## Команды воспроизведения

Установите зависимости из `scripts/requirements-analytics.txt`; для официального XLS нужен `xlrd==2.0.1`. Из корня платформы:

```bash
# Пересчитать производные данные без сети.
python scripts/build_longlife_analytics.py

# Воспроизвести первоначальный срез из компактных входных ZIP.
# Эта команда намеренно возвращает данные к исходному состоянию импорта.
python scripts/import_longlife_release.py --from-inputs
python scripts/build_longlife_analytics.py

# Проверить реальные публикации с ограничением числа сетевых сбоев.
python scripts/refresh_longlife_emiss.py --timeout 8 --retries 0 --max-failures 3

# Проверить только один подтверждённый источник.
python scripts/refresh_longlife_emiss.py --source 62971 --strict

# Повторить доказательные проверки источников и обновления.
python -m unittest discover -s tests -p test_longlife_data.py -v
```

Все команды принимают `--root` для отдельного каталога. Импорт из большой исходной базы поддерживается через `--release /path/NationalProjects_Analytics_1.2.0`, но он не нужен в повседневной сборке. Для изолированного workflow достаточно `scripts/`, `public/data/catalog.json`, опубликованных каталогов данных и загрузок проекта; частные `inputs/` и SQLite не требуются.

Без `--strict` сетевая неудача не прерывает последующее закрытие VPN и публикацию сохранённого набора со статусом ошибки. `--strict` возвращает код 2 при неуспешном или частичном обновлении. Поля `attempted_sources`, `successful_sources`, `published_sources`, `failed_sources`, `deferred_sources` имеют разные значения и не подменяют друг друга.

## Проверки выпуска

29 тестов охватывают контрольные суммы и все исходные ячейки; повторный разбор настоящих выгрузок всех 42 источников; предметные диапазоны; ноль и пропуск; годовой факт и декабрь; скользящее окно; географические оси; прокси и единицы; кадровую совокупность; независимую проверку PCA и сохранение пропусков вне диагностики; дубликаты и пересмотры; усечение JSON; неоднозначные оси XLS; будущие периоды; изменения методики; сетевой сбой; отсутствие таблицы; ограничитель запросов; согласованность JSON и полного CSV. Полные сырые числа не заменялись сведениями из авторских графиков.
