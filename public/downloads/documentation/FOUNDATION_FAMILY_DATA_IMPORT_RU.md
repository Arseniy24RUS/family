# Актуальные данные проекта «Семья»

Платформа использует статистический срез ЕМИСС **15 октября 2026 года** из исследовательского выпуска `NationalProjects_Analytics_1.2.0` от 27 октября 2026 года. Дата сборки сайта не означает новый опрос ЕМИСС. Авторская экспертиза и её документальные источники сохраняют собственные даты.

## Восстановленные входы

В текущий слой импортированы исходные 16 контрактов сайта: для каждого проверены точное совпадение ID ЕМИСС, кода показателя и единицы измерения. Всего **25 627 ячеек**, включая исходные пропуски. Нулевые значения сохранены; флаги качества не заменяют исходные значения, но исключают их из расчётов.

Годовые и квартальные строки бедности многодетных семей, источник 62980, разделены. Явные подписи кварталов распознаются по названиям, без угадывания по порядку ячеек. Показатель посещений культуры 62827 отражает накопление с января, а не независимые месячные значения.

В папке `public/data/latest/` для каждого источника находятся текущий JSON, протокол происхождения и ZIP с нормализованным входом из исследовательской базы, официальными исходными данными и метаданными. Контрольные суммы исходных ответов проверены. Для gzip исходный реестр содержит SHA-256 распакованных байтов; ZIP и опубликованный JSON имеют самостоятельные контрольные суммы. Файлы сетевых запросов в ZIP не включаются.

## Воспроизведение

Повторный импорт из включённых входных пакетов не требует сети или полной исследовательской базы:

```bash
python scripts/import_family_release.py --from-inputs
python scripts/build_indicator_forecasts.py
npm run build
npm run validate
```

Первичный импорт из полного исследовательского выпуска:

```bash
python scripts/import_family_release.py --release /path/to/NationalProjects_Analytics_1.2.0
```

SQLite открывается исключительно для чтения. JSON воспроизводятся побайтово. Отсутствие актуального опубликованного источника или несовпадение его идентификатора вызывает ошибку; подстановка исходного статистического архива запрещена. Старые параметры ссылок `mode=baseline`, `version=archive` и `archive=1` не открывают архивные данные или старые прогнозные кривые.

Действующий workflow обновляет прежние 16 источников «Семьи». При новой проверке дата среза берётся из дат успешного приёма опубликованных источников; неуспешная попытка не выдаётся за обновление статистики. Даты каждого источника указаны отдельно. Тесты сохраняют точные контрольные значения исследовательского выпуска для неизменных входных ZIP и допускают увеличение рядов после следующих штатных загрузок ЕМИСС.

Прогноз СКР и СКР третьих и последующих детей рассчитывается по актуальным месячным входам. Отсутствующие наблюдения не дополняются значениями других территорий. Автоматическое обновление остальных десяти национальных проектов требует отдельного этапа.
