## Что проверяют модульные тесты

JavaScript: отличение нуля от пропуска, медиана, корреляция и связанные ранги, HHI, учебная арифметика DiD, стандартизация, детерминированность k-means и Moran I, исключение константного признака, безопасный CSV, количество строк и источников, территориальные коды и конечность геометрии, разные периодические слои, вложенные областные агрегаты, конфликтующие значения, состав сетей и бюджетные суммы.

Python: извлечение метаданных без исполнения JS, точное сопоставление каталога, неоднозначные поля, отказ от произвольной категории, сохранение повторяющихся POST-параметров, cookies, месяцы и накопительные периоды, десятичные запятые, нечисловые ответы, отсутствующие и нулевые значения, единицы, территории, резкое падение охвата, конфликтующие дубликаты, изменение дополнительного измерения во времени, журнал пересмотров, сохранение прежнего числа при новом пропуске, недоверенное перенаправление, защитная страница, удаление секретных реквизитов из диагностического текста и полный цикл успешной публикации с последующим сбоем на тестовом клиенте.

Тестовые HTTP/XML-ответы являются искусственными фикстурами, а не заявлением об актуальной статистике ЕМИСС. Они не входят в статистический слой сайта.

## Ограничения среды

Браузерный тест выполнен в Chromium через Playwright. Политика среды блокировала обычный переход на HTTP-адрес; поэтому HTML был загружен через `set_content`, а файлы проекта — через route-обработчик с виртуальным базовым адресом. Приложение, его данные, SVG, worker и вычисления исполнялись без подмены. Не проверялись реальные домен, GitHub Pages, сетевые заголовки CDN и production-права репозитория.

Прямой проверочный GET к `https://www.fedstat.ru/indicator/62852` завершился `ConnectError: Temporary failure in name resolution`. Новые статистические данные не получены. Полный обмен с живым сервером ЕМИСС и выполнение workflow на GitHub не подтверждены. В исходной поставке `public/data/latest/manifest.json` поэтому имеет состояние `not_yet_fetched` и не содержит вымышленных дат успешной загрузки.

Не проводились автоматическое переобучение исходных прогнозных моделей, пересмотр авторских выводов, причинная оценка воздействия мер и актуализация нормативных документов. Не выполнялся внешний аудит доступности, проникновения или масштабной нагрузки. Гарантия отсутствия всех возможных ошибок не заявляется.

## Повторить проверки

```bash
npm test
python -m pip install -r scripts/requirements-refresh.txt
python -m unittest discover -s tests -p 'test_*.py' -v
npm run build
npm run validate
```

Для обычного браузерного теста запустите локальный HTTP-сервер и используйте Playwright:

```bash
python -m pip install playwright
python -m playwright install chromium
python -m http.server 8080 --directory docs
# В другом терминале:
python tests/browser_check.py --base http://localhost:8080/
```

Для воспроизведения использованного виртуального теста:

```bash
python tests/browser_check.py --virtual --browser /usr/bin/chromium
```

После внешней публикации отдельно проверьте глубинную ссылку, выбор новой версии статистики, экспорт, доступность документов и реальные результаты первого refresh. Тесты адаптера помогают обнаружить изменение контракта, но не гарантируют сетевой доступ из любого дата-центра.
