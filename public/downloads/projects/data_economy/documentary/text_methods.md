# Текстовая экспертиза экономики данных

Исходная модель использует сохранённые профили 137 документов из 11 проектов. Сравнение средних паспортных профилей охватывает десять проектов одного жанра. Материалы «Семьи» сохранены в корпусе, но исключены из этого ранжирования. Проект новых технологий сбережения здоровья отсутствовал в исходном корпусе. Общий архив 98 паспортных HTML содержит иной набор и используется для проверки десяти выбранных первичных документов.

Каждая строка десяти профилей цифрового проекта сопоставлена с заголовком и описанием адресуемой карточки исходного HTML. Получено 12 479 токенов. Пробелы между текстовыми узлами сохраняют границы слов. Финансовые таблицы и организационные реквизиты в профиль не входят.

TF–IDF использует униграммы и биграммы, максимум 20 000 признаков, минимальную документную частоту 1, максимальную долю документов 0,98, логарифмическую частоту, сглаженную обратную документную частоту и нормирование L2. Вектор проекта строится как среднее нормированных векторов его паспортов с последующим нормированием. Исходный авторский код и контрольная сумма общих профилей доступны в комплекте.

Основная спецификация и русский стемминг повторяют авторскую процедуру. Униграммы, равный вес национального и федерального уровней, только федеральные паспорта и только национальный паспорт являются четырьмя дополнительными проверками платформы. При равном весе уровней усредняются ненормированные средние векторы уровней с коэффициентами 0,5 и затем нормируется общий результат.

Кандидаты связи отбираются для каждого результата среди всех карточек показателей этого национального проекта: до трёх пар с косинусом не менее 0,10. При равных косинусах используется возрастание исходного авторского идентификатора карточки, вычисляемого из типа, SHA документа, XPath и заголовка. Правило проверено по исходному коду и всем 150 отобранным парам. Принадлежность одному федеральному паспорту не обязательна. Отбор сохраняет отдельные URL и XPath обеих карточек. Косинус не является вероятностью, причинным весом или долей общего финансирования.

Словарь содержит 18 тематических категорий. Совпадения внутри категории считаются по объединённому регулярному выражению без перекрытия. Разные категории могут пересекаться. Частота на 1000 токенов сохраняет собственный знаменатель документа. Полные контексты загружаются по выбранному паспорту.
