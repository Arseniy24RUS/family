Национальные проекты

Накопительное обновление 2.12.0-platform.1 содержит все двенадцать экспертиз, актуальные PDF и DOCX редакции от 30.10.2026, официальные логотипы и оптимизированную общую загрузку платформы.

Первый запуск

Распакуйте единый ZIP в отдельную папку. В Windows запустите start_local.bat. В macOS или Linux выполните bash start_local.sh. Требуется Python 3.11 или новее.

При первом запуске отсутствующие копии готового сайта автоматически восстанавливаются из включённых исходников. Одинаковые файлы упакованы один раз, их состав и контрольные суммы записаны в PACKAGE_COPIES.json. Сеть и пересчёт аналитики не нужны. Уже существующие файлы сохраняются.

Браузер откроет http://127.0.0.1:8080/. Оставьте окно сервера открытым. Универсальная команда: python scripts/preview_platform.py. Если порт занят, добавьте --port 8081.

Открыть каталог всех 12 актуальных экспертиз после запуска сервера.

Перед переносом в GitHub Pages

Полный docs/ предназначен для локального просмотра. Для публикации команда npm run build:pages формирует компактную копию .pages/ с проверкой предела 1 ГБ. Оба workflow автоматически строят, проверяют и публикуют её. Все исходные данные сохранены в полном комплекте.

Выполните python scripts/restore_package_copies.py --verify либо обычную сборку. Полученный полный каталог docs/ готов для существующей публикации. Модули и JSON требуют HTTP, поэтому прямое открытие docs/index.html с диска не заменяет запуск сервера.

Инструкция для Codex App находится в documentation/CODEX_HANDOFF_RU.md. Сравните комплект с текущим репозиторием и сохраните более поздние изменения. Подготовка архива не публикует сайт и не отправляет коммиты.
