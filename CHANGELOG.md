# История изменений

## 2.12.0-platform.1 – 30 октября 2026 года

Для всех двенадцати национальных проектов опубликована новая авторская редакция экспертиз: 12 PDF, 12 неизменённых DOCX и единый каталог. PDF подготовлены из предоставленных Word-файлов; содержат 1230 страниц и все 189 исходных изображений. Общие карточки и ссылки на документы используют единый реестр; прежние материалы сохранены как источники расчётной версии.

Официальные векторные логотипы извлечены со страницы 47 брендбука. Логотип выбранного проекта размещён на странице обзора экспертизы. Общая шапка называется «Национальные проекты России» и содержит три ссылки научных организаций; авторы только у «Семьи» и существующие темы сохранены. Мобильная шапка проверяется на ширине 320–1440 пикселей.

Безусловная загрузка всех проектных модулей заменена загрузкой выбранного проекта и его CSS. Данные «Семьи» перестали быть обязательной зависимостью остальных исследований. Общие названия регионов выделены в самостоятельный небольшой файл. Повторное чтение JSON объединено, кэши ограничены, сбои не сохраняются как постоянный результат. Общая навигация сохраняет состояние при изменении фильтров, устаревшие асинхронные ответы не заменяют выбранную страницу.

Компактная публикация GitHub Pages дополнительно сжимает крупные JSON в каталоге данных, сохраняя точные исходные байты. Скачивание из интерактивных и статических страниц возвращает полный JSON; без JavaScript статические ссылки открывают реальный gzip. PDF и другие скачиваемые исходники сохраняют обычные адреса. Полная сборка, проверка данных и существующий способ публикации остаются обязательными.

Для публичного выпуска закреплены точные словари авторской TF–IDF модели: повторный расчёт на разных процессорах воспроизводит контрольные значения без изменения точности сверки. Браузерные проверки читают сжатые данные компактной публикации с проверкой контрольных сумм; даты источников сравниваются независимо. Порядок скачиваемых файлов одинаков на Windows и Linux. CI проверяет именно компактный артефакт GitHub Pages.

Все двенадцать проектов верхней панели имеют полные исследования. Предыдущие материалы, палитры, маршруты, данные и способ публикации сохранены. Этот комплект содержит всё накопленное обновление; архивы предыдущих версий отдельно накладывать не требуется.
