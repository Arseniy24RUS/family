# Входы помесячной передвижки возрастов

Схема `semya.cohort-input/1`, алгоритм `cohort-monthly/1.1.1`.

Базовая численность должна быть **наблюдаемой** и относиться к одной дате для обоих полов. Категории — однолетние возраста 0–99 и открытая группа 100+, в таком порядке. Нулевое значение допустимо; отсутствие значения — нет. Матрица прогнозов из другого проекта не является наблюдением и не принимается вместо базы.

В `public/data/projections/demo_input.json` находится отдельный **синтетический учебный пример**. Он не сопоставлен России или её регионам и открывается только по явному выбору пользователя. Его можно скачать, изменить и загрузить в браузер. Для реального расчёта требуется заменить все синтетические величины документированными входами, включая происхождение.

## Поля

`schema`: строго `semya.cohort-input/1`.

`region_id`, `region_name`: идентификатор и подпись территории. Пакетный скрипт принимает `RU` или идентификатор из `public/data/catalog.json`; браузерный импорт допускает отдельный пользовательский набор и явно подписывает его как локальный файл.

`base_date`: первое число месяца, например `2025-01-01`. `scenario_start`: первое число месяца не ранее базы и не позднее декабря 2030; пользовательские изменения предпосылок начинают действовать с этой даты. При автоматической сборке используется следующий месяц после последнего наблюдения СКР.

`population.male` и `population.female`: по 101 числу. Числа должны быть конечными и неотрицательными, суммы — положительными.

`fertility.annual_tfr`: словарь `год: СКР` с числовыми значениями. `fertility.monthly_tfr`: необязательный словарь `YYYY-MM: значение`, имеющее **годовую размерность**. При совпадении месяца месячная оценка имеет приоритет. Накопительное число рождений не является допустимым СКР.

`fertility.weights`: 101 неотрицательный вес; вне возрастов 15–49 положительные веса запрещены. При расчёте веса нормируются к единице. Возрастной коэффициент = СКР × нормированный вес. Для данных в расчёте на 1000 женщин требуется предварительное деление на 1000; не передавайте такие величины как доли.

`mortality.male`, `mortality.female`: либо `qx` — 101 вероятность смерти за год, от 0 до 1; либо `annual_e0` — словарь годовых значений ожидаемой продолжительности жизни для соответствующего пола. Из e0 строится **модельная** таблица возрастной смертности, не фактическая таблица данного региона. Сценарный сдвиг e0 отключён для напрямую заданных qx.

`migration.male.annual_net`, `migration.female.annual_net`: годовое сальдо в людях, допускается отрицательное. `weights`: 101 неотрицательный возрастной вес, нормируемый к единице. Сальдо делится по месяцам равномерно, затем по возрастам. Отток, приводящий к отрицательной клетке, останавливает расчёт; невыполнимая величина не обрезается.

`sex_ratio`: мальчиков на 100 девочек, по умолчанию 105,6 — предпосылка модели, не заново оцененный показатель. `provenance`: массив записей об источниках, охвате, времени и статусе данных. `assumptions`: массив текстовых допущений.

## Воспроизведение

```bash
python scripts/reproduce_projection.py cohort cohort_package.json
python scripts/reproduce_projection.py cohort input.json --output result.json
```

Для пакетного расчёта поместите документированные JSON в `inputs/cohort/` и выполните:

```bash
python scripts/refresh_demography.py
npm run build
```

Для загрузки наблюдаемой базы из авторского репозитория:

```bash
python scripts/build_indicator_forecasts.py
python scripts/refresh_demography.py --fetch
```

Чтение XLSX реализовано стандартными модулями ZIP/XML Python. Требуются листы `by_age` и `status`; статус каждой принятой базы должен быть явно наблюдаемым. Алгоритм выбирает последний **общий** наблюдаемый год обоих полов. Формат проверяется, а не угадывается при несовпадении. Внешний репозиторий фиксируется по SHA commit для всех пяти файлов одной попытки. Проверенный предыдущий набор сохраняется при недоступности сети.

## Интерпретация выхода

`month` обозначает месяц потоков, `stock_date` — дату запаса после этих потоков. Например, потоки `2030-12` формируют численность на `2031-01-01` — после окончания декабря 2030. Вычисления заканчиваются на этом шаге. Возрастные пирамиды строятся по запасу, не по среднегодовой численности.

Обнуление миграции действует только с `scenario_start`; более ранние месяцы одинаковы в сценариях. Множитель СКР и сдвиг ОПЖ плавно нарастают от сценарной даты до декабря 2030. Годовой компонент без нового значения удерживает последнюю доступную величину **того же региона и пола**. Отдельная сезонная модель числа рождений, смертей и мигрантов внутри года не оценивается. Подключаемая помесячная траектория СКР может содержать календарную составляющую модели показателей версии 1.2.0, с собственными явными ограничениями.

Независимая национальная проекция и сумма региональных проекций не согласуются автоматически: различаются территориальный охват и входные предпосылки. Показатели СКР не усредняются в национальный коэффициент. Сценарный результат не является официальным прогнозом или доказательством действия конкретной меры.
