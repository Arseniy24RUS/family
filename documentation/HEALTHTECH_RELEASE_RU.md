## Состав платформы

Полные исследования представлены для «Семьи», «Молодёжи и детей», «Кадров», «Продолжительной и активной жизни» и «Новых технологий сбережения здоровья». Семь остальных проектов сохраняют подготовленные страницы исследовательской основы. Новый проект отсутствовал в первоначальном перечне одиннадцати, поэтому добавлен двенадцатым без замены прежних проектов.

Общая панель проектов, боковая навигация, фильтры, таблицы, скачивание данных и графиков продолжают интерфейс платформы. На телефоне верхняя панель прокручивается горизонтально. Официальный логотип нового проекта получен с сервера брендбука; основной цвет – `#0A8BBF`. Векторные контуры и цвета сохранены, изменено только поле `viewBox` для единообразного размещения. Локальные Roboto и Bebas Neue, прежние палитры и страница авторов «Семьи» сохранены. Другие проекты не имеют отдельной страницы авторов.

После локального запуска новый раздел доступен по адресу `http://127.0.0.1:8080/#/projects/health_technologies/overview`. Для Windows предусмотрен `start_local.bat`; для macOS/Linux – `bash start_local.sh`. Готовый сайт требует только Python 3 для локального HTTP-сервера. Зависимости аналитики нужны для пересчёта и проверки.

## Прямое обновление ЕМИСС

Адаптер включён в общий `.github/workflows/refresh-emiss.yml`. Он использует существующий сессионный механизм получения официального Excel, проверяет период, единицу, географию, методику, полноту и происхождение перед публикацией. При неуспешном запросе сохраняется последний пригодный набор. Будущий подтверждённый рост числа наблюдений допускается; размер первоначального среза не служит ограничением обновления.

Реальная ограниченная проверка выполнена **29 октября 2026 года в 14:25:16 по Москве** (`2026-10-29T11:25:16+00:00`). Три попытки закончились ошибкой разрешения сетевого имени в среде проверки; 17 источников отложены после достижения лимита. Успешно полученных, опубликованных и изменённых источников – ноль. Отдельное предшествовавшее обращение к карточке 62986 получило HTTP 403. Данный результат не позволяет утверждать общую недоступность сервиса.

`state=failed`, `direct_emiss_verified=false`, дата сохранённой публикации `published_at=2026-09-10`. Числа остаются квалифицированными републикациями НЦСЭД. ## Сборка и проверка

Установка зависимостей и пересчёт выполняются из корня распакованной платформы:

```bash
python -m pip install -r scripts/requirements-analytics.txt
npm test
npm run build
npm run validate
python -m unittest discover -s tests -p "test_*.py"
python -m pip install -r scripts/requirements-browser.txt
python -m playwright install chromium
npm run test:browser
```

Сборка работает без сетевого запроса к ЕМИСС. NLTK закреплён в общих зависимостях аналитики; используемый русский SnowballStemmer не требует загрузки внешнего корпуса NLTK. Компактные первичные входы достаточны для воспроизведения нового проекта без внешней SQLite-базы исследовательского выпуска.

Результаты заключительной проверки зафиксированы в `HEALTHTECH_VALIDATION.json`. Проверяются все прежние и новые JS/Python-тесты, восемь браузерных сценариев через HTTP с префиксом GitHub Pages `/family/`, маршруты, фильтры, выгрузки, сценарии ошибки загрузки, источники, финансовая арифметика и сохранность предыдущего выпуска. Новый раздел проверяется на настольном экране 1440 px и мобильных 390/320 px. Независимый аудит читает исходные XLS и HTML напрямую, без импорта нормализатора или сборщика.

Архив сопровождается `RELEASE_MANIFEST.json` с размерами и SHA256 всех включённых файлов. Упаковщик повторно открывает ZIP, проверяет CRC и каждый SHA256. `DOWNLOAD_MANIFEST.json` рядом с архивом фиксирует итоговый размер и контрольную сумму. Части и отдельные патчи не требуются.
