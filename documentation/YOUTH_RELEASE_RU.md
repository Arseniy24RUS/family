## Статистика и обновление

Сохранены 29 установленных источников ЕМИСС, их первичные ответы, нормализованные наблюдения и происхождение. В начальном проверенном слое содержатся 3 596 ячеек, 3 414 числовых значений и 182 пропуска. Числа доступны по десяти показателям, по 19 источникам имеются метаданные без числовых наблюдений; для восьми позиций реестра источник не установлен.

Четыре сомнительные национальные записи имеют явные флаги: исходные значения сохранены, аналитические значения исключены. Два последних региональных распределения соответствуют собственным периодам: обучение педагогов – июль 2026 года, 85 территорий, медиана 8,21%; охват развития способностей – сентябрь 2026 года, 89 территорий, медиана 97,58%. Федеральные значения берутся из федеральных рядов. Другие территориальные позиции источника сохранены отдельно.

Годовые и оперативные наблюдения имеют разные типы. Сформированы 18 сопоставлений с официальными целями: два годовых и 16 оперативных. Процентные разности измеряются в процентных пунктах; разность составного индекса – в пунктах индекса. Оперативное наблюдение не обозначается как установленное годовое исполнение.

Сборщик `refresh_youth_emiss.py` проверяет идентификатор, название, методику, единицу, периоды, измерения и качество ответа. Он сохраняет последний пригодный ряд при ошибке, пустом ответе или неподтверждённом изменении структуры. Реестр доступности, аналитика и CSV пересчитываются из текущих файлов рядов. При успешном обновлении в библиотеке появляется ссылка на последний проверенный ответ; исходный комплект воспроизведения остаётся отдельно.

Обновление подключено к существующему GitHub workflow «Семьи», включая проверенный маршрут доступа и действующие ссылки на секреты. Значения секретов в архив не входят. Удалённое задание при подготовке пакета не запускалось.

Фактическая проверка из этой среды 29 октября по московскому времени не получила новых данных: три обращения штатного сборщика завершились ошибкой DNS, остальные 26 отложены ограничителем повторных ошибок. Отдельная проверка публичной карточки 62969 через доступное сетевое соединение вернула HTTP 403. Эти результаты относятся к доступу из данной среды. Срез числовых данных остаётся 15.10.2026; время попытки записано отдельно. Код сохранения данных при отказе, успешного пересмотра и последующей недоступности проверен тестами на реальных сохранённых ответах и контролируемых сценариях.

## Документальные расчёты и воспроизводимость

Финансирование рассчитано через `Decimal` без повторного суммирования вложенных источников. Сумма девяти федеральных паспортов за 2025–2030 годы равна 6 181 320 505,53 тыс. руб., национальный план – 6 177 944 262,03 тыс. руб., расхождение – 3 376 243,50 тыс. руб. Все суммы являются номинальными паспортными планами соответствующих редакций.

Сеть сохраняет 277 узлов, 510 исходных связей, 434 связи через общую задачу и 122 лексических кандидата. Отдельный проверенный слой содержит 31 прямую паспортную связь для десяти рассмотренных результатов. Неразрешённые ссылки электронной публикации не трактуются как отсутствие связи в полном паспорте.

Входы текстового анализа сохранены с параметрами, словарями и контрольными суммами. Независимо пересчитаны 137 профилей, 1 246 значений TF-IDF/косинусной близости, 432 тематические ячейки и десять сравнений со стеммингом. Максимальная ошибка числового воспроизведения менее `1e-15`. Большие тексты и контексты подгружаются по выбранному документу; полный набор доступен для скачивания.

## Проверка и практические границы

Проверены 67 тестов JavaScript и полный набор из 120 тестов Python. Контроль сборки проверяет все скачиваемые файлы, происхождение 29 источников, единственность наблюдений, числовые флаги, единицы, 21 текстовую страницу, SHA-256 исходного отчёта и отложенную загрузку корпуса. Результаты браузерной приёмки приведены в `YOUTH_VALIDATION.json`.

Браузерные проверки выполняются в Chromium через настоящий локальный HTTP, включая префикс GitHub Pages `/family/`. Они охватывают прежние функции «Семьи», новые страницы, фильтры, возвращение браузера, мобильное меню, изменение расчётных параметров, CSV/SVG/PNG с встроенным Roboto и скачивание файлов по контрольным суммам. Скриншоты проверки используются для внутренней приёмки и не включены в распространяемый комплект.

Прогнозы и причинные коэффициенты не создаются при отсутствии пригодных данных. Целевой сценарий – условный арифметический расчёт. Разновременные региональные срезы исследуются отдельно. История авторского вывода, статистическая публикация и паспортная редакция сохраняют самостоятельные даты.

## Использование архива

Это единый накопительный пакет с исходниками и готовой папкой `docs/`. После распаковки в Windows запустите `start_local.bat`, затем выберите «Молодёжь» в верхней панели. Для переноса в репозиторий используйте инструкцию `CODEX_HANDOFF_RU.md`. Подготовка ZIP не выполняет push, merge или публикацию в GitHub Pages.
