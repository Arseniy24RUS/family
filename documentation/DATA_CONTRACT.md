# Данные: схема и правила сопоставления

## Первичный срез

Статистическая основа — 19 801 строка, 16 исходных файлов и 15 наблюдаемых индикаторов из 23 в экспертном реестре. Номер `data_21` — локальный идентификатор выгрузки, `2.14.Я.2` — код показателя проекта, `62852` — идентификатор страницы ЕМИСС. Эти три ключа не взаимозаменяемы.

В `catalog.json` перечислены источники, названия, единицы, доступные периоды, регионы, паспортные цели и метаданные. `research.json` содержит сохранённые результаты анализа. `forecasts.json` и `texts.json` хранят прогнозный и текстовый блоки отдельно от оперативной статистики.

## Формат отдельного ряда

Файлы `data/baseline/data_N.json` и опубликованные `data/latest/data_N.json` используют схему `semya.series/1`. Поле `columns` задаёт названия колонок, а `rows` — массивы значений в том же порядке. Основные колонки:

| Ключ | Значение |
|---|---|
| `id` | Идентификатор наблюдения |
| `r` | Нормализованный код территории или null для агрегата/строки без регионального кода |
| `territory` | Полное наименование территории из источника |
| `type` | «год», «месяц» или «накопительно с января» |
| `year` | Год наблюдения |
| `start`, `end` | Границы периода в ISO-формате |
| `label` | Исходный/нормализованный текст периода |
| `value` | Число либо null; ноль остаётся нулём |
| `raw` | Исходная запись ячейки |
| `flag` | Пропуск, отрицательное значение, выход доли за диапазон и другие диагностические состояния |
| `dimensions` | Подтверждённые дополнительные измерения новой выгрузки, если имеются |
| `fetched_at` | Дата получения нового наблюдения; не дата самого статистического периода |

`value` не используется без `source_id`, единицы и типа периода. Годовое значение за 2025 год, декабрь 2025 года и январь–декабрь 2025 года имеют разные ключи. Их нельзя усреднять или заменять друг другом без содержательной проверки.

## Территории

89 кодов соответствуют переданному GeoJSON. Данные могут присутствовать только для 85 территорий или только для федерального агрегата. Карта не удаляет геометрию при отсутствии статистики; она показывает «нет данных».

При вариантах областного агрегата с автономными округами и без них сохраняются исходные строки. Для сопоставления отдельных территорий преимущество получает явно обозначенная компонентная строка «без/кроме автономных округов». Если внутри одного выбранного периода одному коду отвечают несовместимые значения без однозначного основания выбора, число не усредняется: появляется признак конфликта.

Российская Федерация, федеральные округа и субъекты не суммируются в одной сводке. Медиана или среднее по регионам на странице не являются официальным федеральным значением. Такие сводки не взвешены по численности населения, если прямо не указано иное.

## Пропуски, выбросы и границы

Исходные значения не обрезаются к 0 или 100. Число выше 100 в показателе доли показывается с предупреждением; смысл такого значения должен быть проверен по методике. Для показателя прироста посещений культуры значение более 100 само по себе не является тем же нарушением.

В лаборатории значения с диагностическими флагами по умолчанию исключаются из нового расчёта, но пользователь видит правило исключения и число оставшихся наблюдений. Исходный исследователь данных сохраняет все строки. Константный признак не допускается в k-means; недостающие признаки не заполняются средними или медианами.

## Обновления

Первичная загрузка объединяется с архивом по ключу территории и периода, не меняя `baseline`. Новые наблюдения добавляются. Изменённое число для существующего ключа записывается как пересмотр в provenance. Пропуск в новом ответе не удаляет старое числовое значение. Изменение дополнительного измерения уже опубликованного ряда требует ручной проверки и блокирует его незаметную замену.

Статус `unchanged` означает успешную проверку без числовых изменений, а не отсутствие выполненного запроса. При сетевой ошибке дата попытки обновляется, дата успешного получения и последний корректный файл сохраняются. Обновление разных источников может быть частичным; единственная общая дата на верхнем уровне не заменяет даты отдельных источников.

## Целевые значения и метрики

Цели взяты из исследовательского комплекта, не извлекаются автоматически из будущих редакций нормативных документов. Финансовые суммы — план соответствующей версии паспорта. Кластеры, PCA, сети и текстовые метрики — сохранённые результаты. Новая статистика не даёт основания автоматически переименовать их в текущие.

Отдельные оригинальные таблицы используют условные экспертные шкалы и интегральные индексы. Публичное тематическое представление опирается на предметные основания и отдельные наблюдаемые признаки; оригинальные формулировки и таблицы доступны в полном отчёте. Статистическая классификация не представляется оценкой органов власти.
