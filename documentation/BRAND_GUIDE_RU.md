# Оформление платформы «Национальные проекты»

Версия: `2.4.0-healthtech.1`, 29 октября 2026 года.

## Основания

Использован предоставленный пользователем официальный брендбук «Национальные проекты России», 2025. На странице 11 определены шрифты, на странице 47 показаны цветовые направления национальных проектов. Основные цветные логотипы получены в формате RGB/SVG с [официального сервера материалов](https://newbrandbook.nationalpriority.ru). Точные исходные адреса файлов и контрольные суммы записаны в `public/assets/brand/manifest.json`.

Полный исходный PDF не включён в пакет сайта. Для работы платформы нужны только графические файлы и локальные шрифты.

## Типографика

**Roboto** используется для русского и латинского текста, заголовков, интерфейса, таблиц, подписей графиков и представления данных. Включены официальные начертания Regular 400, SemiBold 600 и Bold 700 версии 3.009 (2024), полученные с сервера брендбука. Проверено наличие русских букв, включая Ё/ё, и цифр. Для обычного текста применяется 400, для заголовков и выделения 600, для наиболее выраженных акцентов 700.

**Bebas Neue** используется только для цифровых акцентов. В официальном файле версии 2.000 нет кириллицы, поэтому применять его к русским заголовкам нельзя. Название проекта и названия разделов всегда набираются Roboto. Для текста внутри официального SVG используется уже включённая в него векторная графика.

Шрифты загружаются локально, без внешних обращений к Google Fonts. Для веб-страниц включены WOFF; исходные TTF сохранены для повторной сборки и проверки. Файлы расположены в `public/assets/fonts/`. Тексты лицензий SIL Open Font License 1.1: `Roboto-OFL.txt`, `BebasNeue-OFL.txt`.

```css
@font-face {
  font-family: 'Roboto';
  src: url('../assets/fonts/Roboto-Regular.woff') format('woff');
  font-style: normal;
  font-weight: 400;
  font-display: swap;
}
@font-face {
  font-family: 'Roboto';
  src: url('../assets/fonts/Roboto-SemiBold.woff') format('woff');
  font-style: normal;
  font-weight: 600;
  font-display: swap;
}
@font-face {
  font-family: 'Roboto';
  src: url('../assets/fonts/Roboto-Bold.woff') format('woff');
  font-style: normal;
  font-weight: 700;
  font-display: swap;
}
```

Относительный путь в примере рассчитан для CSS внутри `src/`; для статических страниц исследовательского раздела он вычисляется относительно страницы. В экспорте SVG шрифтовые данные должны встраиваться в сам файл, чтобы подписи не зависели от установленных на компьютере гарнитур.

### Особое правило проекта «Семья»

По решению пользователя уже сложившаяся палитра интерфейса и визуализаций «Семьи» сохраняется: тёмно-синий `#031E4F`, синий `#2947A0`, средний синий `#6280D9`, бирюзовый `#539D96`, светлая бирюза `#A7DBD6`. Официальный SVG логотипа имеет собственный цвет `#00AECD` и не перекрашивается под интерфейс.

### Контраст и смысл цвета

Жёлтый транспортный, светло-зелёный экологический и другие светлые фирменные цвета подходят для заливок, но не гарантируют читаемость мелкого текста на белом фоне. Для текста и границ нужно использовать более тёмный производный оттенок, а для подписи на заливке выбирать белый или тёмный текст по фактическому контрасту. Отрицательные значения и отсутствие данных нельзя обозначать только оттенком: нужны знак, легенда, подпись или штриховка. Цветовые шкалы величин должны сопровождаться единицами измерения и числовыми границами.

## Логотипы

В `public/assets/brand/` находятся 12 SVG, названных по идентификатору проекта. Например: `family.svg`, `long_active_life.svg`, `data_economy.svg`, `health_technologies.svg`.

Сохранены официальные контуры, пропорции, надписи и цвета. В исходных файлах было большое пустое поле макета 1920×1080. Изменён только `viewBox`: к границам знака добавлено свободное поле 12% максимального габарита с каждой стороны. Это облегчает одинаковое размещение логотипов в шапках карточек без деформации. Изображение следует показывать через `<img>` с содержательным `alt`, использовать `object-fit: contain`, не обрезать, не вращать и не добавлять тень к самому знаку.

Логобук указывает минимальную высоту видимого знака 43 px. С учётом включённых полей высота изображения на сайте должна быть не меньше 72 px; рекомендуемое размещение в шапке проекта: 136×116 px на широком экране и 96×82 px на телефоне. На белом фоне используется основная цветная версия. В компактной общей полосе проектов применяются цветная точка и текст, поскольку уменьшенный до размера иконки полный логотип был бы нечитаемым.

Официальные коммуникационные подписи некоторых логотипов короче полных названий национальных проектов: например, «Активная жизнь», «Туризм», «Экономика». В заголовке страницы рядом с логотипом следует показывать полное официальное название проекта; короткая подпись внутри SVG остаётся без изменений.

## Правила для следующих страниц

1. Использовать общую оболочку, навигацию, отступы и компоненты платформы.
2. Получать тему по идентификатору проекта, не прописывать палитру «Семьи» внутри новых диаграмм.
3. Сохранять единые цвета для одной категории во всех графиках одной страницы и явно подписывать смысл цвета.
4. Проверять русский текст, переносы длинных названий и горизонтальную прокрутку таблиц на ширине 320–390 px.
5. Проверять, что сохранённые SVG/PNG содержат подписи, единицы, источник и дату статистического среза.
6. Раздел «Об авторах» показывать только у национального проекта «Семья».

Это исследовательская платформа с официальными графическими материалами национальных проектов. Использование логотипов не должно создавать впечатление, что авторские оценки являются официальной позицией органов власти.
