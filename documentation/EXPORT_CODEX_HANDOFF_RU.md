# Перенос экспортной экспертизы в Codex App

Накопительный комплект `2.11.0-export.1` продолжает `2.10.0-transport.1` и включает все прежние материалы. Полные исследования доступны для всех двенадцати проектов. Сравните комплект с текущей веткой `Arseniy24RUS/family`, сохраняя историю Git, более поздние изменения пользователя и настройки GitHub Pages. Исходный коммит сайта `50ad21c1ad1c94e3cf07857363333df120558617` обозначает происхождение основы и не считается текущей вершиной репозитория.

## Подготовка и содержательная проверка

Распакуйте ZIP в отдельную папку. Выполните `python scripts/restore_package_copies.py --verify` перед сравнением. Побайтово одинаковые файлы упакованы один раз и восстанавливаются по `PACKAGE_COPIES.json`; полный состав задан `RELEASE_MANIFEST.json`. Старые ZIP поверх нового комплекта накладывать не требуется.

Откройте `#/projects/international_export/overview` и все 21 страницу. Проверьте исходный доклад, таблицы, рисунки, сноски, формулы и статические страницы `research/projects/international_export/`. Убедитесь, что источник 62713 различает годовые 10,2% и декабрьские 0,5% за 2025 год. Отклонение прироста выражается в процентных пунктах. Цель регионального стандарта 3.0 нельзя подтверждать историческим источником стандарта 2.0.

Региональная карта использует отдельный источник Банка России. Проверьте 2024 и 2025 годы, объёмы, доли, изменение, категории услуг, выгрузки и территории без данных. Нераспределённая сумма и различия округления должны оставаться видимыми. Вложенные автономные округа нельзя учитывать повторно в областных агрегатах. Региональные операции не равны географии производства.

Финансовые представления должны различать исходные 723,3116451 млрд рублей, подтверждённый трансферт 1,3383563 млрд, скорректированные 721,9732888 млрд и неопределённую полную консолидацию. Периоды бюджетного сравнения 2026/2027 и расходы АПК 2031–2036 сохраните явно.

Проверьте структурные и лексические связи, контексты документов, раскрытый состав 65 профилей и расхождение независимого расчёта с авторским при пороге 0,05. Восемь калькуляторов должны работать с пустыми, допустимыми и недопустимыми входами. В формуле оплаченного экспорта минимум применяется к каждой поставке перед суммированием. Разность разностей и дополнительность не должны автоматически обозначаться установленным эффектом.

Сохраните прежние палитры и новый цвет `#2B3847`. Проверьте мобильную прокрутку верхней панели, все прежние маршруты и страницу `#/authors` только у «Семьи». При смене проекта общая смысловая страница сохраняется, чужие фильтры очищаются.

## Команды

```bash
python scripts/restore_package_copies.py --verify
python -m pip install -r scripts/requirements-analytics.txt
npm test
npm run build
npm run validate
npm run build:pages
python -m unittest discover -s tests -p "test_*.py"
```

Браузерный сценарий расположен в `tests/browser_export.py`. После установки зависимостей из `scripts/requirements-browser.txt` и Chromium запустите `python tests/run_browser.py --directory .pages --suite browser_export --output <каталог_вне_репозитория>`. Проверка должна выполняться по HTTP и с префиксом `/family/`, соответствующим Pages. Общий браузерный набор сохраняет сценарии прежних проектов. Границы выполненной при подготовке архива проверки зафиксированы в `EXPORT_VALIDATION_RU.md`.

Для просмотра готового комплекта используйте `start_local.bat` или `bash start_local.sh`. Требуется Python 3.11 или новее. После запуска адрес нового раздела – `http://127.0.0.1:8080/#/projects/international_export/overview`. Прямое открытие HTML с диска не обеспечивает HTTP-загрузку модулей и данных.

## Обновление и публикация

Команда обновления – `python scripts/refresh_export_emiss.py`, отдельного источника – `--source 62713`. Параметр ручного workflow – `export_source`, статус задания – `export_state`. Обычная сборка автономна и не восстанавливает старый срез поверх более поздних рядов. `import_export_release.py --from-inputs` предназначен только для явного восстановления исходного набора. Ошибка сети сохраняет прежние наблюдения, происхождение и дату успешной публикации.

Региональные XLSX Банка России включены в `inputs/international_export/context/` и опубликованы в разделе исходных данных. `build_export_regional_context.py` пересчитывает их автономно с проверкой исходных SHA-256. Дата получения файлов не подменяет период наблюдения. Автоматический запрос этих таблиц не добавляется к обновлению ЕМИСС.

Полный `docs/` служит входом для `.pages/`. Оба workflow проверяют размер и точность восстановления сжатых статистических рядов перед публикацией. Секреты и существующий маршрут доступа к ЕМИСС сохраните; секреты не входят в архив. Подготовка комплекта не публикует сайт. После проверки подготовьте изменения для просмотра перед публикацией.
