# Национальный проект «Туризм и гостеприимство»

Срез исходных данных: 2026-10-15. Анализ: версия 1.0.0.

Числовые данные: 5 из 10 показателей. Региональные наблюдения есть у 1 показателей. Диагностические прогнозы построены для 2 рядов, справочные сценарии — для 89. Разные частоты, категории и территориальные определения образуют отдельные ряды.

Документированные цели имеются по 0 показателям. Статус: `not_in_supplied_inputs`. Без целевого значения нельзя определить недостижение или перевыполнение. Архивные цели не объявляются актуальной редакцией паспорта.

Сигналы, требующие просмотра: 90 рядов. Причины раскрыты в forecast_quality.csv. Наличие такого сигнала не означает автоматически ошибку наблюдения.

Картографические срезы находятся в regional_snapshots.csv. Каждый срез относится к единой дате и периодичности. Федеральные ориентиры не распределены произвольно между регионами. Номера источников и ключи рядов связывают CSV с основной SQLite.

Все доступные изображения проекта выбираются через ../../index.html. Их исходные данные доступны в SQLite и общем реестре ../../tables/figures.csv. Таблицы с одними заголовками означают, что для соответствующей процедуры нет достаточных входов; числа туда не подставлены.
